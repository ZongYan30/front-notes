# 先计划再行动

使用langchain的`TodoListMiddleware`即可。

```python
from deepagents import create_deep_agent
from langchain_python.core.config import anthropic_settings
from langchain.chat_models import init_chat_model
from langchain.agents.middleware import TodoListMiddleware

model = init_chat_model(
    model=anthropic_settings.default_model,
    model_provider="anthropic",
    thinking={"type": "disabled"},
)

# TodoListMiddleware
agent = create_deep_agent(model=model, middleware=[TodoListMiddleware()])

```

TodoListMiddleware会做以下工作：

1. 注入系统提示词
2. 添加新工具`write_todos`
   - 图状态添加 todos 字段
   - todos中的status有: pending, completed,in_progress

测试提示词：

```text
请设计一个“7 天 LangGraph 入门训练营”，并完成以下任务：

1. 明确目标学员、前置知识和学习目标
2. 设计 7 天课程大纲
3. 为每天设计一个练习和验收标准
4. 将需求、课程大纲、验收清单分别写入三个文件
5. 重新读取三个文件，检查内容是否一致
6. 如果发现遗漏或冲突，修改对应文件
7. 最后汇总交付结果

这是一个多步骤任务。请使用待办清单管理整个执行过程：开始任务前创建待办事项，每完成一步立即更新状态，不要等到最后一次性全部标记完成。
```
