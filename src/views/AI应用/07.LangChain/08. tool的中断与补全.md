# tool的中断与补全
认识一下创建deepAgent的之后自带的一个中间件:`PatchToolCallsMiddleware.before_agent`

作用:
当给AI提问`搜索当前黄金趋势`，发送后直接中断请求。

```text
Human: 搜索当前黄金趋势
AI: 调用工具`web_search`
中断了
Human: 继续搜索啊。
```

这个时候AI就会产生两次工具调用，后来的AI会产生疑惑，为什么会有两次调用，容易出现幻觉。

为了保持上下文完整，我们需要:
```
Human: 搜索当前黄金趋势
AI: 调用工具`web_search`
Tool: 工具被中断了
Human: 继续搜索啊。
AI: 重新调用工具`web_search`
```
而`PatchToolCallsMiddleware.before_agent`就是来实现这个功能的。

## 使用
创建deepAgent:
```python
from deepagents import DeepAgentState, create_deep_agent
from langchain.chat_models import init_chat_model
from langchain.messages import RemoveMessage
from langchain_python.core.config import anthropic_settings
from langchain_python.tools import tools

model = init_chat_model(
    model=anthropic_settings.default_model,
    model_provider="anthropic",
    thinking={"type": "disabled"},
)

agent = create_deep_agent(model=model, tools=tools)
```

打开agentServer:
```sh
1. 搜索最近的黄金走势 (执行到tool节点，点击取消，查看model的图状态)
2. 重新输入：继续搜索
```

第一步的图状态为
```sh
Human: 搜索最近的黄金走势
AI: 调用web_search
```

第二步中间件的图状态为
```sh
DeleteMessage: Message ID '__remove_all__' has been deleted
Human: 搜索最近的黄金走势
AI: 调用web_search
Tool: Tool call web_search with id toolu_f9da959a1b054fc5924399eb was cancelled - another message came in before it could be completed.
Human: 继续啊
```

## 中间件实现解析
可以猜测，该中间件的实现
```python
from deepagents import DeepAgentState
from langchain.messages import RemoveMessage

# 先清空，再追加
def node(state: DeepAgentState):
    return {
        "messages": [RemoveMessage("__remove_all__")]
    }
```
