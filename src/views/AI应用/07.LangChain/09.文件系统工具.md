# 文件系统工具

![](https://zongyan30.github.io/front-assets/agent/file-backend.png)

deepagent默认提供了需要tools工具，其中就包括文件系统相关的，例如:
```
ls 
grep 
glob 
delete 
edit_file 
write_file 
read_file
```

工具只负责调用，而`后端`负责执行，`backend`很多地方都会用到，例如skillMiddleware等。

点击查看`create_deep_agent`源码，可以找到`StateBackend`的实现，其中规定后端需要实现`BackendProtocol`这个抽象类。

## 使用
```python
from deepagents import DeepAgentState, create_deep_agent
from langchain.chat_models import init_chat_model
from langchain.messages import RemoveMessage
from langchain_python.core.config import anthropic_settings
from langchain_python.tools import tools
from deepagents.backends import FilesystemBackend
from deepagents.backends.protocol import BackendProtocol, SandboxBackendProtocol

model = init_chat_model(
    model=anthropic_settings.default_model,
    model_provider="anthropic",
    thinking={"type": "disabled"},
)


agent = create_deep_agent(
    model=model,
    tools=tools,
    backend=FilesystemBackend("E:/学习资料/渡一/02.渡一AI应用开发/langchain-deepagent/temp"),
)
```

在agentServer给AI输入以下内容，查看生成的文档:
```text
请写一首夏天的诗，保存到md文档中
```
