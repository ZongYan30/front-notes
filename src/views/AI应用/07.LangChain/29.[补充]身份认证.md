# 身份认证

在访问所有API前，加一层身份认证。
![](https://zongyan30.github.io/front-assets/agent/auth.png)

认证流程:

```
API接口请求--> 运行authenticate --> 最后会在config['configuration']['langgraph_auth_user']注入用户消息
```

## 实现认证

新建`core/auth.py`，主要借助langgraph_sdk的`Auth`类。使用装饰器`@auth.authenticate`来实现认证逻辑。

```python
from typing import Never

from langgraph_sdk import Auth

auth = Auth()

# 抛出异常
def _raise_invalid_token() -> Never:
    raise Auth.exceptions.HTTPException(status_code=401, detail="invalid token")


# 模拟用户认证数据
MOCK_USER: dict[str, Auth.types.MinimalUserDict] = {
    "user_1": {
        "identity": "user_id_001",  # 必填
        "display_name": "铁锤",  # 可选
        "permissions": ["thread:create", "assistant:create"],  # 可选
    },
    "user_2": {
        "identity": "user_id_002",  # 必填
        "display_name": "丧彪",  # 可选
        "permissions": ["thread:create", "assistant:create"],  # 可选
    },
}


# 认证逻辑
@auth.authenticate
async def authenticate(
    authorization: str | None,
) -> Auth.types.MinimalUserDict:
    """验证 Authorization: Bearer <token> 并返回当前用户。"""
    if not authorization:
        _raise_invalid_token()

    schema, sep, token = authorization.partition(" ")

    if not token:
        _raise_invalid_token()

    # 解析token，通常要访问后端web服务（用户中心）
    if token not in MOCK_USER:
        _raise_invalid_token()

    return MOCK_USER[token]
```

## 验证

```python
from langgraph_sdk import get_client

client = get_client(url="http://127.0.0.1:2024")

assistant_id = 'c3cdd36b-80ed-5994-823a-a26808ae54cd'
assistant_id
```

```python
# 创建新线程
thread = await client.threads.create(
    metadata={"__name__": "身份认证测试"},
    headers={
        "authorization":"Bearer user_1"
    }
)
thread_id = thread["thread_id"]
thread_id
```

```python
await client.runs.wait(
    thread_id=thread_id,
    assistant_id=assistant_id,
    input={
        "messages":[
            {"role":"user", "content":"分析最近的黄金走势"}
        ]
    },
    headers={
        "authorization":"Bearer user_1"
    }
)
```

```python
await client.runs.list(
    thread_id="01a0757b-50c6-7fd3-981b-76e0ce874f0f",
    headers={
        "authorization":"Bearer user_1"
    }
)
```
