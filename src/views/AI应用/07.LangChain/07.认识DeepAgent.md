# Langchain阶段总结

`LangChain` 基于 `LangGraph` 构建，它提供了以下核心功能：

1. 统一了模型和消息的外观，从而屏蔽了不同模型服务商的差异
2. 提供了便捷的工具封装能力
3. 基于`LangGraph`构建了`Agent`工作流
   - 提供了`response_format`实现消息结构化
   - 提供了强大灵活的中间件机制，并内置了大量中间件

# DeepAgent
DeepAgent是基于`langchain`进行的再次封装，在一个agent应用中：
langchain + langgraph + DeepAgent是同时进行使用的
选择顺序为：DeepAgent --> langchain --> langgraph

## 创建一个DeepAgent
```sh
uv add deepagents
```

```python
from deepagents import create_deep_agent
from langchain.chat_models import init_chat_model
from langchain_python.core.config import anthropic_settings

model = init_chat_model(
    model=anthropic_settings.default_model,
    model_provider="anthropic",
    thinking={"type": "disabled"},
)

agent = create_deep_agent(model=model)

```

注册`langgraph.json`
```json
{
  "python_version": "3.13",
  "source": {
    "kind": "uv",
    "root": "."
  },
  "graphs": {
    "conding_agent": "langchain_python.agents.coding_agent:agent"
  },
  "env": ".env"
}
```

启动`agentServer`,查看一下图结构

```sh
langgraph dev
```

会发现，DeepAgent的图中加了大量的中间件，这些中间件更偏向于生产级的应用。
