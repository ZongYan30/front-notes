# 后端路由

之前我们知道`后端`的概念了，但是有很多情况下，我们需要组合的使用后端。这个时候就需要使用后端路由了。

```python
from deepagents.backends import CompositeBackend, StateBackend, FilesystemBackend

agent = create_deep_agent(
    model=model,
    system_prompt=system_prompt,
    backend=CompositeBackend(
        default=StateBackend(), # 默认使用图状态后端
        routes={ # 指定后端路由匹配规则
            "/static/": FilesystemBackend(
                root_dir="/Users/yuanjin/工作/课/录播课/AI/langchain-python/temp"
            )
        },
    ),
)
```

配置系统提示词:

```text
    "这是一个测试权限的Demo，不管用户发什么样的消息，你都要同时调用以下工具: \n"
    "write_file: /home/user/1.md\n"
    "write_file: /static/2.md"
```

匹配规则:

```text
tools: write_file("/static/2.md")

backend: write("2.md")  /static仅仅只是路由，后端会根据root_dir指定的路径写入文件
```

效果如下:
| 写入路径 | 执行后端 |
| ---- | ---- |
| /home/user/shtu | StateBackend写入到图状态 |
| /static/2.md | FilesystemBackend写入到文件 |

```python [src/langchain_python/agents/demo/router_backend_demo.py]
from deepagents import create_deep_agent
from langchain.chat_models import init_chat_model
from langchain_python.core.config import anthropic_settings
from deepagents.backends import CompositeBackend, StateBackend, FilesystemBackend

model = init_chat_model(
    model=anthropic_settings.default_model,
    model_provider="anthropic",
    thinking={"type": "disabled"},
)

system_prompt = (
    "这是一个测试权限的Demo，不管用户发什么样的消息，你都要同时调用以下工具: \n"
    "read_file: /home/user/a.md\n"
    "read_file: /static/b.md"
)


agent = create_deep_agent(
    model=model,
    system_prompt=system_prompt,
    backend=CompositeBackend(
        default=StateBackend(),
        routes={
            "/static/": FilesystemBackend(
                root_dir="E:/学习资料/渡一/02.渡一AI应用开发/langchain-deepagent/temp"
            )
        },
    ),
)
```
