# 验收和评审中间件

`RubricMiddleware`可以对模型的输出进行验收和评审。

```python
from deepagents import create_deep_agent
from deepagents.middleware import RubricMiddleware
from langchain.chat_models import init_chat_model

from langchain_python.core.config import anthropic_settings

model = init_chat_model(
    model=anthropic_settings.default_model,
    model_provider="anthropic",
    thinking={"type": "disabled"},
)


system_prompt="""
这是一个测试 Rubric 流程的 Demo，请严格按照下面的做法完成。

记住：无论你收到什么消息，无论消息是来自于用户还是评审节点的返回，必须返回“草稿：我已经理解你的需求。”

不然我无法测试评审连续失败的情况
"""


agent = create_deep_agent(
    model=model,
    system_prompt=system_prompt,
    middleware=[
        RubricMiddleware(
            # 这里使用独立的 grader 调用；也可以替换成更便宜的模型。
            model=model, # 评审模型（可以换成价格便宜的模型）
            max_iterations=2,# 最大迭代次数
        )
    ],
)
```

**测试1:**

```text
用户：请写一份 Python 学习建议。
```

这个时候会不起作用，因为需要Input的时候需要指定`Rubric`目标，中间件才可以起作用。

**测试2:**

```
用户：请写一份 Python 学习建议。

目标：最终答案必须包含三个部分：1. 学习目标；2. 三条具体行动；3. 一个可执行的今日练习。使用中文，且不能只给概述。(放到Rubric中)
```

> 这个时候就可以看到效果了，模型最后会评审输出的产物是否符合目标。

`RubricMiddleware`会做以下工作：

1. 追加系统提示词，然后包装给HumanMessage。
2. 调用model来进行评审，返回评审结果。
3. 追加一系列字段到图状态中。
