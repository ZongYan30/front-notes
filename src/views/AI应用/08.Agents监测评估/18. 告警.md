# 告警

告警：当对agent的某些指标观测达到设定的阈值，就会通过邮箱/短信的方式通知到相关人员。

告警面板：在langfuse的`Alert`模块
方式: 采用webhooks的方式 连接到我们的agent
回调地址：http://host.docker.internal/api/webhooks/langfuse/alerts

## 告警 Webhook 流程

![Langfuse 发送告警 Webhook，Agent Server 验证签名后接收事件；签名无效时返回 401](https://zongyan30.github.io/front-assets/agent/langfuse-alert-webhook.svg)

1. langfuse中配置告警及地址
2. agentServer中支持到告警webhook，并且实现对应的告警处理逻辑
3. 配置告警触发条件，例如模型调用费用突然升高、用户等待时间变长等

## 常见告警及配置示例

- 模型调用费用突然升高
  - View: Observations
  - Measure: Total Cost
  - Aggregation: Sum
  - Filters:
    - Environment any of default
    - Type any of GENERATION

- 用户等待时间变长
  - View: Observations
  - Measure: Latency
  - Aggregation: P95
  - Filters:
    - Environment any of production
    - Name any of 入口 Observation 名称

- 工具调用/Agent 步骤错误变多
  - View: Observations
  - Measure: Count
  - Aggregation: Count
  - Filters:
    - Environment any of production
    - Level any of ERROR
    - Type any of TOOL

- 入口请求量异常下降
  - View: Observations
  - Measure: Count
  - Aggregation: Count
  - Filters:
    - Environment any of production
    - Name any of 入口 Observation 名称

- 回复质量下降
  - View: Scores (numeric)
  - Measure: Value
  - Aggregation: Average
  - Filters:
    - Name any of answer_quality
    - Environment any of production

- 合规检查不通过占比升高
  - View: Scores (boolean)
  - Measure: Value
  - Aggregation: Average
  - Filters:
    - Name any of policy_pass
    - Environment any of production

- 特定负面分类积累
  - View: Scores (categorical)
  - Measure: Count
  - Aggregation: Count
  - Filters:
    - Name any of 分类 Score 名称
    - Categorical Value any of unsafe
    - Environment any of production

## 实现告警

1. langfuse新建Automation

```
Automation Name: AgentServer Alert Hook
trigger: Alert
action type: Webhook
action url: http://host.docker.internal/api/webhooks/langfuse/alerts
headers: 默认的即可
```

> 将生成的webhook secret复制，等会儿连接agentServer时需要使用

2. 接着新建一个Alert

```
Metric Definition
- view: observations
- measure: total cost
- aggregation: sum //表示对这5分钟单位时间内的总费用的求和

Add Filter
- Environment: default
- Type: GENERATION

Alert Condition
Alert threshold: 0.01 //超过1分钱就报警
warning threshold: 0.05

Notifications
- title: 【费用报警】消耗到达阈值
```

3. AgentServer中实现告警

- .env中新建env环境变量
- config中新增alert_webhook_secret字段 (pandytic)
- app中新增`/api/webhooks/langfuse/alerts`接口接收webhook处理逻辑
- app/main.py中注册新增的路由

```sh
.
└── src/

        ├── app/
        │   ├── alert_webhook.py
        │   └── main.py
        └── config/
            └── langfuse_settings.py
```

```python [src/ai_eval/config/langfuse_settings.py]
from ai_eval.config.base_settings import BaseSettingsWithEnv


class LangfuseSettings(BaseSettingsWithEnv):
    secret_key: str = ""
    public_key: str = ""
    base_url: str = ""
    experiment_webhook_secret: str = ""
    alert_webhook_secret: str = ""

    model_config = {"env_prefix": "LANGFUSE_"}


langfuse_settings = LangfuseSettings()
```

```python [src/ai_eval/app/alert_webhook.py]
import logging

from fastapi import APIRouter, Request
from fastapi.responses import JSONResponse

from ai_eval.config.langfuse_settings import langfuse_settings
from ai_eval.utils.langfuse_signature import verify_signature

router = APIRouter()


@router.post("/api/webhooks/langfuse/alerts")
async def receive_alert(request: Request):
    # 先做签名验证
    if not await verify_signature(request, langfuse_settings.alert_webhook_secret):
        return JSONResponse({"error": "Invalid Webhook Signature"}, status_code=401)

    # 通知业务：邮件、短信 （接入公司SMS接口）
    event = await request.json()

    return JSONResponse({"ok": True}, status_code=200)
```

```python [src/ai_eval/app/main.py]
from fastapi import FastAPI
from ai_eval.app.experiment_webhook import router as experiment_router
from ai_eval.app.alert_webhook import router as alert_router

app = FastAPI()
app.include_router(experiment_router)
app.include_router(alert_router)
```
