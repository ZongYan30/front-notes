# 演练场Playground

演练场主要用来测试不同模型在不同情况下的表现。

1. 进入setting --> LLM Connection配置模型信息
   输入模型接口协议, provider,apikey,model_id等信息
   创建连接

2. 进入演练场，支持自定义tools和系统提示词，以及完整的上下文。

## json Schema格式

```json
{
  "type": "object",
  "properties": {
    "location": {
      "type": "string",
      "description": "城市名，如 北京 / Shanghai"
    },
    "days": {
      "type": "integer",
      "description": "查询未来几天，默认 3",
      "minimum": 1,
      "maximum": 7,
      "default": 3
    },
    "unit": {
      "type": "string",
      "description": "温度单位",
      "enum": ["celsius", "fahrenheit"],
      "default": "celsius"
    }
  },
  "required": ["location"],
  "additionalProperties": false
}
```
