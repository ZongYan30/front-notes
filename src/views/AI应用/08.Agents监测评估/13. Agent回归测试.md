# Agent回归测试

![](https://zongyan30.github.io/front-assets/agent/langfuse-dataset-experiment-evaluation-workflow.png)

本章节主要是针对task任务的编写，让task任务能够连接到agentServer中的模型，然后获得模型的真实输出。

```
用户输入 --> 期待输出  --> 真实输出
```

## 代码改动

为了解决之前的一些问题，需要对代码进行一些改动。改动如下:

1. 因为task要跑模型，而模型又在agentServer中，需要连接到agentServer中。
   - 新增env，支持在benchmark中连接到agentServer中的环境变量。
   - 新增config/benchmark_settings.py，来获取环境变量
   - BENCHMARK/experiment.py 连接到agentServer中的模型
   - mock_user(提供一个用户给benchmark使用)

2. 修复athropic的读取不到缓存问题
   - 新增utils/anthropic_compat.py，来修复athropic的缓存问题
   - create_model.py 中引入anthropic_compat.py,创建模型时先覆盖

```python [src/ai_eval/utils/anthropic_compat.py]
"""Compatibility fixes for Anthropic-compatible providers."""

from __future__ import annotations

from collections.abc import Mapping
from typing import Any

from pydantic import BaseModel


def patch_nullable_cache_creation_usage() -> None:
    """Treat nullable cache TTL counters as zero in langchain-anthropic.

    Some Anthropic-compatible providers return both cache TTL keys with null
    values. langchain-anthropic 1.7.1 adds those values as integers and raises
    ``TypeError`` before it can return the model response.
    """
    import langchain_anthropic.chat_models as chat_models

    original = chat_models._create_usage_metadata
    if getattr(original, "_llm_ops_nullable_cache_fix", False):
        return

    def create_usage_metadata(anthropic_usage: BaseModel) -> Any:
        cache_creation = getattr(anthropic_usage, "cache_creation", None)
        if cache_creation:
            if isinstance(cache_creation, BaseModel):
                values = cache_creation.model_dump()
                values.update({key: value or 0 for key, value in values.items()})
                cache_creation = cache_creation.model_copy(update=values)
            elif isinstance(cache_creation, Mapping):
                cache_creation = {
                    key: value or 0 for key, value in cache_creation.items()
                }
            anthropic_usage = anthropic_usage.model_copy(
                update={"cache_creation": cache_creation}
            )
        return original(anthropic_usage)

    create_usage_metadata._llm_ops_nullable_cache_fix = True  # type: ignore[attr-defined]
    chat_models._create_usage_metadata = create_usage_metadata
```

from ai_eval.config.anthropic_settings import anthropic_settings
from ai_eval.utils.anthropic_compat import patch_nullable_cache_creation_usage


def create_model(**kwargs):
    # 修复athropic的缓存问题
    patch_nullable_cache_creation_usage()
    config = {
        "model": anthropic_settings.default_model,
        "thinking": {"type": "disabled"},
        "model_provider": "anthropic",
    }
    config.update(kwargs)

    model = init_chat_model(**config)
    return model

## task交互模型

```
jupyter进程运行实验 --> 找到数据集 --> 通过task执行 --> 请求另一个进程(agentServer) --> 拿到结果 --> 得到真实输出
```

先让task连接到agentserver来发出请求，得到实际的输出

```python
from langgraph_sdk import get_client as get_agent_client


async def experiment_task(*, item: DatasetItem, **kwargs):
    # 连接到agentServer,将input作为user message发送，得到实际输出
    async with get_agent_client(
        url=benchmark_settings.agent_server,# localhost:8000
        headers={"Authorization": f"Bearer {benchmark_settings.user_id}"}, #传递用户身份
    ) as client:
        result = await client.runs.wait(
            thread_id=None,# 没有线程id就是无状态执行
            assistant_id=benchmark_settings.graph_id, # 可以指定agent的id，会自动获取assistant_id
            input={"messages": [{"role": "user", "content": item.input}]}, # 输入user message
        )

    last_message = result.get("messages")[-1]  # type: ignore
    return last_message["content"]
```

这个时候运行实验，就会发现,task已经可以正常运行了。

## 问题讨论

虽然能运行了，但是现在会出现两个问题：

**问题一**:
实验中的点击某个observation,发现是和agentserver中断的。 我们期望是相连起来的。

根因: 需要将agentServer中的内容接到实验的根中。

解决思路:

```text
1. 获取当前experiment的trace_id和observation_id，传递给agentServer。
2. agentServer借助`langchain.CallbackHandler`追踪中间件
3. 可以通过metadata传输
```

**问题二**:
default环境下的observation,发现评估器依旧进行了评估，我们做的目的是离线评估，评估器只需要评估线上环境的observation。

根因: agentServer中执行的环境是default，应该切换为sdk-experiment。

思路：也通过experiment的metadata将env环境传递过来。

## 补充知识：

1. `CallbackHandler`允许接收`trace_context`，来指定挂载点

```python
from langfuse.langchain import CallbackHandler

def trace_wrapper(agent_factory):
    async def _trace(config: RunnableConfig, runtime: ServerRuntime):
        trace_handler = CallbackHandler(
            trace_context={
                "trace_id": "实验trace_id", # 指定这次挂载到哪个trace上
                "observation_id": "实验observation_id",# 指定这次挂载到哪个observation上
            },
        )
        agent = await agent_factory()

        assert runtime.user is not None
        agent = agent.with_config(
            callbacks=[trace_handler],
        )
        return agent

    return _trace
```

我们只需要指定上方的`trace_context`，指定挂载到实验的某个trace和observation上,就可以完成连接了。

2. 获取实验中的trace_id和observation_id,以及环境

```python
from opentelemetry import trace

trace_id = langfuse.get_current_trace_id()  # 获取当前实验的traceid
parent_span_id = langfuse.get_current_observation_id()  # 获取当前实验的parent_span_id
span_attributes = getattr(trace.get_current_span(), "attributes", {})
env = span_attributes.get("langfuse.environment")  # 获取当前实验的环境
```

## 解决问题

接下来

1. 只需要在实验task中获取当前实验的`trace_id`和`observation_id`和`env`
2. 执行的时候传递metadata给`main_agent`的trace`CallbackHandler`
3. 在`main_agent`指定`CallbackHandler`的时候，获取到metadata，传递给`CallbackHandler`指定挂载点即可。

```python [src/ai_eval/benchmarks/experiment.py]
from langfuse.api import DatasetItem
from langfuse import get_client
from ai_eval.benchmarks.dataset import get_items
from langgraph_sdk import get_client as get_agent_client
from ai_eval.config.benchmark_settings import benchmark_settings
from opentelemetry import trace

langfuse = get_client()


async def experiment_task(*, item: DatasetItem, **kwargs):
    trace_id = langfuse.get_current_trace_id()  # 获取traceid
    parent_span_id = langfuse.get_current_observation_id()  # 获取当前的parent_span_id
    span_attributes = getattr(trace.get_current_span(), "attributes", {})
    env = span_attributes.get("langfuse.environment")

    # 连接到agentServer,将input作为user message发送，得到实际输出
    async with get_agent_client(
        url=benchmark_settings.agent_server,
        headers={"Authorization": f"Bearer {benchmark_settings.user_id}"},
    ) as client:
        result = await client.runs.wait(
            thread_id=None,
            assistant_id=benchmark_settings.graph_id,
            input={"messages": [{"role": "user", "content": item.input}]},
            metadata={
                "trace_id": trace_id,
                "parent_span_id": parent_span_id,
                "trace_environment": env,
            },
        )

    last_message = result.get("messages")[-1]  # type: ignore
    return last_message["content"]



def run_experiment(name: str, dataset_name: str, description: str | None = ""):
    items = get_items(dataset_name)
    # 运行实验
    langfuse.run_experiment(
        # 给实验取个名字
        name=name,
        # 如果不配置，则使用name+当前时间自动生成
        run_name=None,
        description=description,
        # 此次实验针对哪些数据项
        data=items,
        task=experiment_task,  # type: ignore
    )
```

```python [src/ai_eval/utils/trace_wrapper.py]
from langfuse.langchain import CallbackHandler
from langchain_core.runnables import RunnableConfig
from langfuse.types import TraceContext
from langgraph_sdk.runtime import ServerRuntime
from langfuse import propagate_attributes
from contextlib import asynccontextmanager


def trace_wrapper(agent_factory):
    @asynccontextmanager
    async def _trace(config: RunnableConfig, runtime: ServerRuntime):
        metadata = config.get("metadata", {})
        trace_id: str = metadata.get("trace_id", "")
        parent_span_id: str = metadata.get("parent_span_id", "")
        trace_context: TraceContext | None = None
        if trace_id and parent_span_id:
            trace_context = {"trace_id": trace_id, "parent_span_id": parent_span_id}

        trace_handler = CallbackHandler(trace_context=trace_context)
        agent = await agent_factory()
        thread_id = config.get("configurable", {}).get("thread_id")
        assert runtime.user is not None
        agent = agent.with_config(
            callbacks=[trace_handler],
            metadata={
                "langfuse_session_id": thread_id,
                "langfuse_user_id": runtime.user.identity,
            },
        )

        env = metadata.get("trace_environment", "")
        if env:
            with propagate_attributes(environment=env):
                yield agent
        else:
            yield agent

    return _trace




def trace_wrapper(agent_factory):
    async def _trace(config: RunnableConfig, runtime: ServerRuntime):
        trace_handler = CallbackHandler()
        agent = await agent_factory()

        assert runtime.user is not None
        agent = agent.with_config(
            callbacks=[trace_handler],
        )
        return agent

    return _trace

```
