# 实现MCP服务器

```python [安装依赖]
# https://github.com/modelcontextprotocol/python-sdk/tree/v1.28.1
!uv add mcp==1.28.1
```

```python [导入模块]
from mcp.server.fastmcp import FastMCP
```

## 定义MCP服务器

```python [创建MCP实例]
mcp = FastMCP(
    "Weather Service",
    json_response=True,
)
```

## 定义工具函数

```python [定义天气工具]
# https://www.juhe.cn/ 聚合数据有一些免费API接口，有兴趣的同学自行使用
@mcp.tool()
async def get_weather(city: str = "成都") -> dict[str, str]:
    """Get weather data for a city"""
    return {
        "city": city,
        "temperature": "22",
        "condition": "多云",
        "humidity": "65%",
    }
```

## 运行服务

```python [直接运行]
# mcp库底层使用 starlette + uvicorn 启动 http 服务
mcp.run(transport="streamable-http")
```

```python [Jupyter中运行]
# for jupyter

import threading

def run():
    """在独立线程中运行服务器"""
    mcp.run(transport="streamable-http")

t = threading.Thread(target=run)
t.start()
```

## agent接入MCP服务器
因为是自己启动的mcp服务器，所以只需要按照MCP协议将自己服务器配置项写好就行。

agent会根据mcp来调用use_mcp(),然后通过`mcp`库的ClientSession的`call_tool()`来调用自己的注册的mcp工具

:::code-group
```json [mcp.json]
{
  "servers": {
    "time": {
      "type": "stdio",
      "command": "uvx",
      "args": [
        "mcp-server-time"
      ]
    },
    "microsoft-learn": {
      "type": "http",
      "url": "https://learn.microsoft.com/api/mcp"
    },
    "my-weather": {
      "type": "http",
      "url": "http://localhost:8000/mcp/"
    }
  }
}
```

```python [main.py]
from agent.agent import Agent
from agent.printer import ModelPrinterListener


def main() -> None:
    listener = ModelPrinterListener()
    agent = Agent(model_listener=listener)

    agent.session.print_friendly()
    agent.invoke("今天天气如何？")
    agent.session.save()


if __name__ == "__main__":
    main()
```
:::
