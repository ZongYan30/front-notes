# Ollama

## 本地模型

- `Pytorch + Transformers`：主要是用于本地训练、微调，也可以进行本地推理，但需要自行适配硬件加速
- `Ollama`：一键部署和运行开源大模型的命令行工具，内置量化支持和 GPU 加速
- `llama.cpp`：高性能 C/C++ 推理引擎，主打 CPU 推理和多种量化方案
- `vLLM`：高吞吐量推理框架，基于 PagedAttention 技术，适用于生产环境部署
- `MLX`：Apple 官方 ML 框架，专为 Apple Silicon 设计的本地推理方案
- `LM Studio`：带图形界面的桌面应用，支持一键下载和运行本地开源模型
- `LocalAI`：提供 OpenAI 兼容 API 的本地推理服务，方便现有应用无缝切换

## 下载安装

自行下载安装：https://ollama.com/

```shell
ollama -v
```

Ollama官方仓库：https://ollama.com/library

设置环境变量：`OLLAMA_MODEL_SERVER="https://mirror.ollama.com"`

```shell
# 拉取模型到本地
ollama pull qwen3-vl
# 查看已下载的模型
ollama list
# 删除模型
ollama rm <模型名称>
# 查看模型信息
ollama show <模型名称>
# 运行模型
ollama run <模型名称>
# 查看目前的服务
ollama ps
```

访问：http://localhost:11434/ ，查看服务是否正在运行



测试接口：

```shell

```


## openAI SDK接入

### 环境准备

**安装依赖：**

```shell
uv add openai==1.74.0 python-dotenv==1.2.2
```

**配置 `.env` 文件：**

在项目根目录创建 `.env` 文件，配置 Ollama 服务地址和模型名称：

```shell
OPENAI_API_KEY=ollama
OPENAI_BASE_URL=http://localhost:11434/v1
OPENAI_MODEL=qwen3-vl
```

> Ollama 默认不需要 API Key，这里填写任意字符串即可；`OPENAI_BASE_URL` 指向本地 Ollama 服务的 `/v1` 路径，实现 OpenAI 接口兼容。

### 基本对话

### 关闭思维链

部分推理模型（如 `qwen3-vl`）默认会输出思考过程，可通过 `extra_body` 显式关闭：

```python
response = client.chat.completions.create(
    model=config.OPENAI_MODEL,
    messages=[
        {"role": "user", "content": "你是谁"}
    ],
    extra_body={
        "thinking": {
            "type": "disabled"
        }
    }
)
print(response.to_json())
```

> 注意：`qwen3-vl` 可能无法直接关闭思考模式，此时建议在 system prompt 中引导模型「少思考，直接给出答案」。

### 流式响应

#### 方式一：原始流式输出（逐 Chunk 打印）

```python
import sys

stream = client.chat.completions.create(
    model=config.OPENAI_MODEL,
    messages=[
        {"role": "system", "content": "少思考，简洁回答"},
        {"role": "user", "content": "从1数到10"}
    ],
    stream=True
)

for chunk in stream:
    print(chunk)
    sys.stdout.flush()
```

#### 方式二：格式化流式输出（区分思考与内容）

使用 `print_stream` 工具函数，自动识别推理块和内容块，分别用不同颜色展示：

```python
from utils.stream_print import print_stream
import sys

stream = client.chat.completions.create(
    model=config.OPENAI_MODEL,
    messages=[
        {"role": "system", "content": "少思考，简洁回答"},
        {"role": "user", "content": "从1数到10"}
    ],
    stream=True
)
print_stream(stream)
```

输出效果：
- 青色文字：模型的「思考过程」（reasoning）
- 红色文字：模型的「最终回答」（content）
- 自动标记思考开始/结束、内容开始/结束

### 多模态：视觉能力

使用 `qwen3-vl` 等视觉模型识别本地图片：

```python
from utils.stream_print import print_stream
from utils.img_base64 import to_dataurl

# 读取本地图片并转换为 Base64 DataURL
dataurl = to_dataurl("menu.png")

stream = client.chat.completions.create(
    model=config.OPENAI_MODEL,
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "请描述这张图片的内容"},
            {"type": "image_url", "image_url": {"url": dataurl}}
        ]
    }],
    stream=True
)
print_stream(stream)
```

关键步骤：
1. 通过 `to_dataurl()` 将本地图片（PNG/JPG/GIF/WEBP）转为 `data:image/xxx;base64,...` 格式
2. 在 `messages[].content` 中使用数组形式，同时传入 `text` 和 `image_url`
3. 支持流式输出，实时展示识别结果

```python [stream_resp.py]
from dataclasses import dataclass


@dataclass
class Chunk:
    type: str = ""
    content: str = ""


def chunk_generator(stream):
    is_on_reasoning = False
    for chunk in stream:
        if len(chunk.choices) == 0:
            continue
        delta = chunk.choices[0].delta
        content = delta.content
        reasoning_content = getattr(delta, "reasoning_content", None)
        if not reasoning_content:
            reasoning_content = getattr(delta, "reasoning", None)

        if reasoning_content:
            if not is_on_reasoning:
                is_on_reasoning = True
                yield Chunk(type="reasoning_start")
            yield Chunk(type="reasoning", content=reasoning_content)
        if content:
            if is_on_reasoning:
                is_on_reasoning = False
                yield Chunk(type="reasoning_end")
                yield Chunk(type="content_start")
            yield Chunk(type="content", content=content)

    yield Chunk(type="content_end")
```

```python [stream_print.py]
from utils.stream_resp import chunk_generator
import sys


def print_stream(stream):
    for chunk in chunk_generator(stream):
        if chunk.type == "reasoning_start":
            print("思考：")
        elif chunk.type == "reasoning_end":
            print()
        elif chunk.type == "content_start":
            print()
            print("内容：")
        elif chunk.type == "content_end":
            print()
            print("====输出完毕====")
        elif chunk.type == "reasoning":
            print(f"\033[36m{chunk.content}\033[0m", end="")
        elif chunk.type == "content":
            print(f"\033[31m{chunk.content}\033[0m", end="")
        sys.stdout.flush()
```

```python [img_base64.py]
import base64


def to_base64(image_path):
    with open(image_path, "rb") as image_file:
        base64_image = base64.b64encode(image_file.read()).decode("utf-8")
    return base64_image


def to_dataurl(image_path: str) -> str:
    b64_data = to_base64(image_path)

    lower_path = image_path.lower()
    if lower_path.endswith(".png"):
        mime = "image/png"
    elif lower_path.endswith((".jpg", ".jpeg")):
        mime = "image/jpeg"
    elif lower_path.endswith(".gif"):
        mime = "image/gif"
    elif lower_path.endswith(".webp"):
        mime = "image/webp"
    else:
        mime = "image/octet-stream"

    data_url = f"data:{mime};base64,{b64_data}"
    return data_url
```

**各模块职责说明：**

| 模块 | 功能 |
|------|------|
| `config.py` | 使用 `python-dotenv` 从 `.env` 文件加载环境变量，统一导出 API Key、Base URL、模型名 |
| `stream_resp.py` | 核心流式解析器：将 OpenAI SDK 的原始 chunk 流转换为带类型标签的结构化事件流（`reasoning_start/reasoning/reasoning_end/content_start/content/content_end`），同时兼容 `reasoning_content` 和 `reasoning` 两种字段名 |
| `stream_print.py` | 基于 `chunk_generator` 的终端打印工具，用 ANSI 颜色区分思考（青）和内容（红），并打印起止标记 |
| `img_base64.py` | 本地图片 → Base64 → DataURL 的转换工具，自动识别 PNG/JPG/GIF/WEBP 等常见格式，用于多模态视觉输入 |
