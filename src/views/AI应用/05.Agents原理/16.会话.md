## 问题场景：手动维护消息列表

在没有会话管理的情况下，每次调用模型都需要手动传入完整的消息列表，**无法自动保留上下文**。

### 第 1 次调用

```python
resp = model.invoke_stream([
    {"role": "system", "content": render_prompt("system")},
    {"role": "user", "content": "uv是什么？"}
])

print_stream(resp)
```

### 第 2 次调用（上下文丢失）

```python
resp = model.invoke_stream([
    {"role": "system", "content": render_prompt("system")},
    {"role": "user", "content": "如何安装？"}
])

print_stream(resp)
```

> ⚠️ 此时模型不知道「如何安装」指的是 uv，因为上一轮的消息没有被保留。

## 解决方案：使用 Session 会话管理

`Session` 类会自动维护消息历史，模型回复后会自动将 assistant 消息追加到会话中。

```python
from agent.session import Session

session = Session()
session.add_message({"role": "system", "content": render_prompt("system")})
session.add_message({"role": "user", "content": "uv是什么？"})
# 第一次调用
resp = model.invoke_stream(session)

print_stream(resp)
```

### 查看当前会话内容

```python
import json

print(session.id)
print(json.dumps(session.messages, ensure_ascii=False, indent=2))
```

### 第 2 次调用（上下文自动保留）

```python
session.add_message({"role":"user", "content": "如何安装？"})
# 第2次调用
resp = model.invoke_stream(session)

print_stream(resp)
```

> ✅ 此时模型能理解「如何安装」指的是上一轮提到的 uv，因为消息历史由 Session 统一管理。

### 再次查看会话内容

```python
import json

print(session.id)
print(json.dumps(session.messages, ensure_ascii=False, indent=2))
```

### 持久化：保存会话到文件

```python
session.save()
```

会话文件会保存到 `agent/sessions/{session_id}.json`，后续可通过 `Session.load(session_id)` 恢复。

# 最佳实践

在使用会话功能的时候，不管以何种方式实现，应该遵循以下法则：

- **历史上下文不可修改**

  不满足此条，会导致难以命中模型服务商的 prompt cache
- **上下文中应保留思维链**

  不满足此条，会导致推理上下文丢失，从而导致模型回复质量下降

```python [model.py]
from .config import openai_settings
from dataclasses import dataclass
from typing import cast
from openai import OpenAI
from .message import Message
from collections.abc import Iterator
from .session import Session


@dataclass
class Chunk:
    type: str = ""
    content: str = ""


@dataclass
class Model:
    model_name: str = openai_settings.model
    _client: OpenAI = OpenAI(
        api_key=openai_settings.api_key,
        base_url=openai_settings.base_url,
    )

    # 普通回复
    def invoke(self, messages: list[dict] | Session):
        session = None

        if isinstance(messages, Session):
            session = messages
            messages = session.messages

        response = self._client.chat.completions.create(
            model=self.model_name,
            messages=cast(list, messages),
        )

        if session:
            session.add_message(response.choices[0].message.to_dict())

        return response

    # 流式回复
    def invoke_stream(self, messages: list[dict] | Session) -> Iterator[Chunk]:
        session = None

        if isinstance(messages, Session):
            session = messages
            messages = session.messages

        stream = self._client.chat.completions.create(
            model=self.model_name,
            messages=cast(list, messages),
            stream=True,
        )

        is_on_reasoning = False
        full_reasoning_content = ""
        full_content = ""
        reasoning_field = ""  # 思维链字段

        for chunk in stream:
            if not chunk.choices:
                continue

            delta = chunk.choices[0].delta
            content = delta.content
            reasoning_field_temp = "reasoning_content"
            reasoning_content = getattr(delta, reasoning_field_temp, None)

            if not reasoning_content:
                reasoning_field_temp = "reasoning"
                reasoning_content = getattr(delta, reasoning_field_temp, None)

            if reasoning_content:
                reasoning_field = reasoning_field_temp
                full_reasoning_content += reasoning_content
                if not is_on_reasoning:
                    is_on_reasoning = True
                    yield Chunk(type="reasoning_start")
                yield Chunk(type="reasoning", content=reasoning_content)

            if content:
                full_content += content
                if is_on_reasoning:
                    is_on_reasoning = False
                    yield Chunk(type="reasoning_end", content=full_reasoning_content)
                    yield Chunk(type="content_start")
                yield Chunk(type="content", content=content)

        yield Chunk(type="content_end", content=full_content)

        if session:
            msg = {"role": "assistant", "content": full_content}
            if reasoning_field:
                msg[reasoning_field] = full_reasoning_content
            session.add_message(msg)
```

```python [printer.py]
from dataclasses import dataclass
import sys


@dataclass
class PrinterConfig:
    show_reasoning: bool = True
    reasoning_color: str = "36"
    content_color: str = "31"


# 打印模型响应
def print_response(response, config: PrinterConfig | None = None):
    if config is None:
        config = PrinterConfig()

    message = response.choices[0].message
    reasoning_content = getattr(message, "reasoning_content", None)

    if not reasoning_content:
        reasoning_content = getattr(message, "reasoning", None)

    if reasoning_content and config.show_reasoning:
        print(f"\033[{config.reasoning_color}m{reasoning_content}\033[0m")
        print()

    content = message.content
    if content:
        print(f"\033[{config.content_color}m{content}\033[0m")


# 打印模型响应流
def print_stream(chunk_iterator, config: PrinterConfig | None = None):
    if config is None:
        config = PrinterConfig()
    for chunk in chunk_iterator:
        if chunk.type == "reasoning_start":
            if config.show_reasoning:
                print("思考：")
        elif chunk.type == "reasoning_end":
            if config.show_reasoning:
                print()
        elif chunk.type == "content_start":
            print()
            print("内容：")
        elif chunk.type == "content_end":
            print()
            print("====输出完毕====")
        elif chunk.type == "reasoning":
            if config.show_reasoning:
                print(f"\033[{config.reasoning_color}m{chunk.content}\033[0m", end="")
        elif chunk.type == "content":
            print(f"\033[{config.content_color}m{chunk.content}\033[0m", end="")
        sys.stdout.flush()
```

```python [prompt.py]
import os
import platform
import subprocess

from jinja2 import Environment, FileSystemLoader


# 获取当前工具目录
def get_cwd() -> str:
    return os.getcwd()


# 获取是否加入git管理
def get_is_git() -> bool:
    result = subprocess.run(
        ["git", "rev-parse", "--is-inside-work-tree"],
        capture_output=True,
        text=True,
        timeout=5,
    )
    return result.returncode == 0 and result.stdout.strip() == "true"


# 获取当前系统语言
def get_language() -> str:
    system = platform.system()
    if system == "Darwin":
        result = subprocess.run(
            ["defaults", "read", "-g", "AppleLocale"],
            capture_output=True,
            text=True,
            timeout=5,
        )
        return result.stdout.strip()
    elif system == "Windows":
        import ctypes

        lcid = ctypes.windll.kernel32.GetUserDefaultLCID()  # type: ignore
        buf = ctypes.create_unicode_buffer(256)
        ctypes.windll.kernel32.GetLocaleInfoW(lcid, 0x5C, buf, 256)  # type: ignore
        return buf.value
    return ""


# 渲染提示模板
def render_prompt(prompt_name: str) -> str:
    template_dir = os.path.join(os.path.dirname(__file__), "prompt")
    # 创建 Jinja2 环境（Environment），指定从文件系统加载模板
    env = Environment(loader=FileSystemLoader(template_dir))
    # 加载指定的 .j2 模板文件
    template = env.get_template(f"{prompt_name}.j2")
    # 把变量传入模板
    return template.render(
        language=get_language(),
        cwd=get_cwd(),
        is_git=get_is_git(),
    )


print(f"cwd: {get_cwd()}")

print(f"language: {get_language()}")
```

```python [session.py]
from pathlib import Path
import uuid
import json


class Session:
    def __init__(self):
        self.id = str(uuid.uuid4())  # 会话id
        self.messages: list[dict] = []  # 会话消息列表

    # 保存会话
    def add_message(self, message: dict):
        self.messages.append(message)

    # 保存会话到文件
    def save(self):
        sessions_dir = Path(__file__).parent / "sessions"
        sessions_dir.mkdir(parents=True, exist_ok=True)

        data = {
            "id": self.id,
            "messages": self.messages,
        }

        path = sessions_dir / f"{self.id}.json"
        with open(path, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    # 从文件加载会话
    @classmethod
    def load(cls, session_id: str):
        path = Path(__file__).parent / "sessions" / f"{session_id}.json"

        with open(path, encoding="utf-8") as f:
            data = json.load(f)

        session = cls()
        session.id = data["id"]
        session.messages = data["messages"]
        return session
```

## 模块职责说明

| 模块                 | 职责                                                                                       | 核心技术                                         |
| ------------------ | ---------------------------------------------------------------------------------------- | -------------------------------------------- |
| `config.py`        | 统一管理 OpenAI API 配置，自动加载 `.env` 文件                                                        | `pydantic-settings`                          |
| `message.py`       | 定义三种消息类型（System/User/Assistant）                                                          | `dataclass`, `ABC`                           |
| `model.py`         | 封装 OpenAI 客户端，支持普通/流式调用；兼容 `list[dict]` 与 `Session`；流式时自动将 assistant 消息（含思维链）追加回 Session | `openai SDK`, Iterator/Generator, Session 集成 |
| `printer.py`       | 终端彩色打印，区分推理过程（青色）与正文（红色），支持流式逐字输出                                                        | ANSI 转义码, `sys.stdout.flush()`               |
| `prompt.py`        | 采集环境信息（CWD、git、系统语言），通过 Jinja2 渲染系统提示词模板                                                 | `jinja2`, `platform`, `subprocess`           |
| `session.py`       | 会话管理：UUID 会话 ID、消息列表维护、JSON 持久化保存/加载                                                     | `uuid`, `json`, `pathlib`                    |
| `prompt/system.j2` | 系统提示词模板，包含角色定义、规则约束、条件语言渲染、环境信息注入                                                        | Jinja2 模板语法                                  |
