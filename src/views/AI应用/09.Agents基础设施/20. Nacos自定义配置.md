# Nacos自定义配置

## 配置文件最佳实践

现在有两个地方可以存放项目配置：

- 环境变量env: 适合存放固定不变,重要度高(api key)的配置
- nacos配置中心: 适合存放动态变化的配置。

## nacos配置

1. 在 `Nacos` 中添加自定义配置
   - Group: deal_pilot
   - Data ID: sandbox_config
   - 配置格式：yaml
   - 配置内容：
   ```yaml
   # 创建沙箱使用的镜像，对应 Sandbox.create(image=...)。
   image: "opensandbox-python-node:1.0"

   # 沙箱创建后存活的时间，单位秒；对应 Sandbox.create(timeout=...)。
   timeout_seconds: 600

   # 等待沙箱创建并就绪的最长时间，单位秒；对应 Sandbox.create(ready_timeout=...)。
   ready_timeout_seconds: 180

   # 单次命令执行允许等待的最长时间，单位秒；对应 RunCommandOpts(timeout=...)。
   command_timeout_seconds: 90
   ```
2. `nacos_schema.py`新增OpenSandboxConfig类，来定义结构类型
   ```python
   from pydantic import BaseModel, Field
   from deal_pilot.config.openai_settings import openai_settings


   # Model的类型
   class AgentModelConfig(BaseModel):
       name: str = Field(default=openai_settings.default_model)
       thinking: bool = Field(default=True)
       temperature: float | None = Field(default=None)
       top_p: float | None = Field(default=None)


   # Mcp的类型
   class MCPServerConfig(BaseModel):
       name: str
       url: str
       disabled_tools: list[str] = Field(default_factory=list)


   # AgentSpec的类型
   class AgentSpec(BaseModel):
       name: str = Field()
       description: str = Field(default="")
       system_prompt: str = Field(default="")
       model: AgentModelConfig = Field(default_factory=AgentModelConfig)
       skills: list[str] = Field(default_factory=list)
       mcps: dict[str, MCPServerConfig] = Field(default_factory=dict)
       tools: list[str] = Field(default_factory=list)
       subagents: list[str] = Field(default_factory=list)

   # 沙箱配置
   class OpenSandboxConfig(BaseModel):
       image: str = Field(default="python:3.12-slim", min_length=1)
       timeout_seconds: int = Field(default=600, gt=0)
       ready_timeout_seconds: int = Field(default=180, gt=0)
       command_timeout_seconds: int = Field(default=90, gt=0)
   ```
3. 新增`nacos_config.py`，来获取nacos配置中心的配置

   请求 `GET /nacos/v3/client/cs/config`（`groupName` + `dataId`），`yaml.safe_load` 解析后交给 pydantic 校验；`get_config` 用泛型把「配置名 + schema 类型」绑定在一起，取不到配置时返回默认构造的对象。
   ```python
   from typing import Literal
   from pydantic import BaseModel
   import yaml
   import httpx
   import asyncio
   from deal_pilot.config.nacos.nacos_access_token import get_access_token
   from deal_pilot.config.nacos.nacos_schemas import OpenSandboxConfig
   from deal_pilot.config.nacos_settings import nacos_settings
   from deal_pilot.utils.func_tools import func_cache


   # 枚举类，定义配置名称
   _GROUP_NAME = "deal_pilot"
   type ConfigName = Literal["sandbox_config"]


   # 获取nacos配置
   @func_cache(ttl=nacos_settings.ttl, lazy=True)
   async def _get_config_content(config_name: ConfigName) -> str | None:
       access_token = await get_access_token()

       async with httpx.AsyncClient(
           base_url=nacos_settings.server_address, headers={"accessToken": access_token}
       ) as client:
           response = await client.get(
               "/nacos/v3/client/cs/config",
               params={
                   "namespaceId": nacos_settings.namespace_id,
                   "groupName": _GROUP_NAME,
                   "dataId": config_name,
               },
           )
           response.raise_for_status()
           response = response.json()

       if response["code"] != 0:
           return None

       response = response["data"]["content"]
       return response


   # 获取配置
   async def get_config[T: BaseModel](config_name: ConfigName, schema: type[T]) -> T:
       content = await _get_config_content(config_name)

       if content is None:
           return schema()

       dict = yaml.safe_load(content)  # 读取yaml内容，转为dict字典
       return schema.model_validate(dict)


   if __name__ == "__main__":
       result = asyncio.run(get_config("sandbox_config", OpenSandboxConfig))
       print("==>", result)
   ```
