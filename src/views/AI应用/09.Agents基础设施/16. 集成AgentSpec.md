## 核心思路
核心就是通过nacos的api接口，获取到agent spec的配置，只不过我们需要拆分成一些工具。

### 1. 定义期望的agent spec的类型

用 `pydantic` 定义三层类型：`AgentModelConfig`（模型）、`MCPServerConfig`（单个 MCP）、`AgentSpec`（整体配置）。`AgentSpec.mcps` 是 `名字 -> MCPServerConfig` 的字典，不是名字数组。

`src/deal_pilot/config/nacos/nacos_schemas.py`

```python
from pydantic import BaseModel, Field
from deal_pilot.config.openai_settings import openai_settings


# Model的类型
class AgentModelConfig(BaseModel):
    name: str = Field(default=openai_settings.default_model)
    thinking: bool = Field(default=True)
    temperature: float | None = Field(default=None)
    top_p: float | None = Field(default=None)


# Mcp的类型
class MCPServerConfig(BaseModel):
    name: str
    url: str
    disabled_tools: list[str] = Field(default_factory=list)


# AgentSpec的类型
class AgentSpec(BaseModel):
    description: str = Field(default="")
    system_prompt: str = Field(default="")
    model: AgentModelConfig = Field(default_factory=AgentModelConfig)
    skills: list[str] = Field(default_factory=list)
    mcps: dict[str, MCPServerConfig] = Field(default_factory=dict)
    tools: list[str] = Field(default_factory=list)
    subagents: list[str] = Field(default_factory=list)
```

### 2. 函数依赖切分

核心实现`get_agent_spec`函数，但是mcp我们期望构造一个`MCPServerConfig`类型的对象，所以需要先实现`get_mcp_config`函数。

```python
get_agent_spec()       # 获取agent spec的配置
 - get_access_token()  # 登录换取 token
 - get_mcps()          # 获取所有mcp的配置
    - get_mcp_config() # 获取单个mcp的配置
```

### 3. 实现`get_mcp_config`函数

请求 `GET /nacos/v3/admin/ai/mcp`，把 `backendEndpoints[0]` 拼成 URL，`toolsMeta` 中未启用的工具收进 `disabled_tools`；取不到返回 `None`。

`src/deal_pilot/config/nacos/nacos_mcp.py`

```python
# 获得单个mcp配置
@func_cache(ttl=nacos_settings.ttl, lazy=True)
async def get_mcp_config(mcp_name: str) -> MCPServerConfig | None:
    # print(f"--> 真正执行了 get_mcp_config({mcp_name})")  # 加这行
    access_token = await get_access_token()

    # 从nacos获取单个mcp配置
    async with httpx.AsyncClient(
        base_url=nacos_settings.server_address, headers={"accessToken": access_token}
    ) as client:
        response = await client.get(
            "/nacos/v3/admin/ai/mcp",
            params={"namespaceId": nacos_settings.namespace_id, "mcpName": mcp_name},
        )
        response = response.json()
        if response["code"] != 0:
            return None

    # 构造mcp配置对象
    response = response["data"]
    endpoints = response.get("backendEndpoints", [])
    if len(endpoints) == 0:
        return None
    backend = endpoints[0]
    url = f"{backend["protocol"]}://{backend["address"]}:{backend["port"]}{backend["path"]}"

    tools_meta = response.get("toolSpec", {}).get("toolsMeta", {})
    disabled_tools = [
        name for name, value in tools_meta.items() if not value.get("enabled", True)
    ]
    return MCPServerConfig.model_validate(
        {"url": url, "disabled_tools": disabled_tools, "name": mcp_name}
    )
```

### 4. 实现`get_mcps`函数

`asyncio.gather` 并发拉取，整理成 `dict[str, MCPServerConfig]`，丢掉 `None`。

`src/deal_pilot/config/nacos/nacos_mcp.py`

```python
# 获得所有mcp配置
async def get_mcps(mcp_names: list[str]) -> dict[str, MCPServerConfig]:
    tasks = [get_mcp_config(mcp_name) for mcp_name in mcp_names]  # 并发所有异步
    mcp_configs = await asyncio.gather(*tasks)  # 类似Promise.all
    return {config.name: config for config in mcp_configs if config is not None}
```

### 5. 缓存装饰器`@func_cache`

考虑到极致性能，mcp一般配置很少改动，当频繁请求的时候，我们期望做一个缓存，避免每次请求都去nacos获取。
目标： 实现一个通用的装饰器`@func_cache`,传递一个缓存时间参数`ttl`，默认值为5秒。

功能：

```text
    """按函数和参数缓存结果，支持同步函数与异步函数。

    1. 同一参数在首次调用或到期刷新时只执行一次，其余调用等待同一结果。
    2. 开启 ``lazy`` 后，到期且已有缓存时立即返回旧值，并在后台刷新。
    3. 刷新失败时保留旧值；首次计算失败时将异常传给所有等待者。

    参数：
        ttl: 缓存有效时间，单位为秒，必须大于等于零。
        lazy: 到期时是否先返回旧值，再在后台刷新。
    """
```

思路：

- env文件中新增环境变量`NACOS_TTL = 5`
- config中的pydantic模型中新增一个字段`ttl`，默认值为5秒
- 把需求告诉AI，实现`@func_cache`装饰器

```python [src/deal_pilot/utils/func_tools.py]
"""函数级内存缓存工具。"""

import asyncio
import inspect
import logging
import threading
import time
from concurrent.futures import Future, ThreadPoolExecutor
from functools import wraps
from typing import Any


_logger = logging.getLogger(__name__)
_refresh_executor = ThreadPoolExecutor(thread_name_prefix="func-cache-refresh")


def _freeze(value: Any) -> Any:
    """把常见容器参数转换成可哈希的缓存键，并保留类型信息。"""
    if isinstance(value, dict):
        return (dict, frozenset((_freeze(key), _freeze(item)) for key, item in value.items()))
    if isinstance(value, (list, tuple)):
        return (type(value), tuple(_freeze(item) for item in value))
    if isinstance(value, (set, frozenset)):
        return (type(value), frozenset(_freeze(item) for item in value))

    try:
        hash(value)
    except TypeError as exc:
        raise TypeError(f"参数类型 {type(value).__name__} 无法用于缓存键") from exc
    return (type(value), value)


def func_cache(*, ttl: int = 120, lazy: bool = False):
    """按函数和参数缓存结果，支持同步函数与异步函数。

    同一参数在首次调用或到期刷新时只执行一次，其余调用等待同一结果。
    开启 ``lazy`` 后，到期且已有缓存时立即返回旧值，并在后台刷新。
    刷新失败时保留旧值；首次计算失败时将异常传给所有等待者。

    参数：
        ttl: 缓存有效时间，单位为秒，必须大于等于零。
        lazy: 到期时是否先返回旧值，再在后台刷新。
    """
    if ttl < 0:
        raise ValueError("ttl 不能小于零")

    def decorator(func):
        signature = inspect.signature(func)
        cache: dict[Any, tuple[Any, float]] = {}
        inflight: dict[Any, Future[Any]] = {}
        lock = threading.Lock()

        def make_key(*args, **kwargs):
            bound = signature.bind(*args, **kwargs)
            bound.apply_defaults()
            return tuple((name, _freeze(value)) for name, value in bound.arguments.items())

        def publish(key, future: Future[Any], *, result: Any = None, error: BaseException | None = None):
            with lock:
                if error is None:
                    cache[key] = (result, time.monotonic() + ttl)
                inflight.pop(key, None)

            if error is None:
                future.set_result(result)
            else:
                future.set_exception(error)

        def get_state(key):
            """在锁内决定返回缓存、等待计算，还是发起一次计算。"""
            with lock:
                entry = cache.get(key)
                if entry is not None and time.monotonic() < entry[1]:
                    return "cached", entry[0], None

                future = inflight.get(key)
                if entry is not None and lazy:
                    if future is None:
                        future = Future()
                        inflight[key] = future
                        return "refresh", entry[0], future
                    return "cached", entry[0], None

                if future is not None:
                    return "wait", None, future

                future = Future()
                inflight[key] = future
                return "compute", None, future

        if inspect.iscoroutinefunction(func):

            async def calculate_async(key, future: Future[Any], args, kwargs, *, background: bool):
                try:
                    result = await func(*args, **kwargs)
                except BaseException as exc:
                    publish(key, future, error=exc)
                    if background:
                        _logger.exception("异步缓存后台刷新失败：%s", func.__qualname__)
                else:
                    publish(key, future, result=result)

            @wraps(func)
            async def async_wrapper(*args, **kwargs):
                key = make_key(*args, **kwargs)
                state, value, future = get_state(key)
                if state == "cached":
                    return value
                if state in ("compute", "refresh"):
                    assert future is not None
                    try:
                        asyncio.get_running_loop().create_task(
                            calculate_async(key, future, args, kwargs, background=state == "refresh")
                        )
                    except BaseException as exc:
                        publish(key, future, error=exc)
                        if state == "refresh":
                            _logger.exception("异步缓存后台刷新启动失败：%s", func.__qualname__)
                if state == "refresh":
                    return value
                assert future is not None
                # 等待者取消时不取消共享计算，其他等待者仍可取得结果。
                return await asyncio.shield(asyncio.wrap_future(future))

            return async_wrapper

        def calculate_sync(key, future: Future[Any], args, kwargs, *, background: bool):
            try:
                result = func(*args, **kwargs)
            except BaseException as exc:
                publish(key, future, error=exc)
                if background:
                    _logger.exception("同步缓存后台刷新失败：%s", func.__qualname__)
            else:
                publish(key, future, result=result)

        @wraps(func)
        def sync_wrapper(*args, **kwargs):
            key = make_key(*args, **kwargs)
            state, value, future = get_state(key)
            if state == "cached":
                return value
            if state == "refresh":
                assert future is not None
                try:
                    _refresh_executor.submit(calculate_sync, key, future, args, kwargs, background=True)
                except BaseException as exc:
                    publish(key, future, error=exc)
                    _logger.exception("同步缓存后台刷新启动失败：%s", func.__qualname__)
                return value
            assert future is not None
            if state == "compute":
                calculate_sync(key, future, args, kwargs, background=False)
            return future.result()

        return sync_wrapper

    return decorator
```

:::

要点：

- `ttl` 字段默认 `0`，由 `.env` 的 `NACOS_TTL = 5` 覆盖（`NACOS_` 前缀自动映射）。
- 缓存键 = 函数 + 参数，按 `agent_name` / `mcp_name` 分别缓存。
- `inflight` + `Future` 保证并发只打一次 Nacos；`lazy=True` 时先返回旧值、后台刷新。

> 之后对`skill、mcps、agentSpec`都可以做一次缓存，优化性能。

当前已加缓存的：`get_mcp_config`、`get_agent_spec`。

### 6. 实现`get_agent_spec`函数

请求 `GET /nacos/v3/client/ai/agentspecs`（`name` + `label=production`）；`data.content` 是 JSON 字符串需二次 `json.loads`，`mcps` 交给 `get_mcps` 换成配置字典，系统提示词取自 `data.resource["instruction_{agent_name}/AGENTS__MD"]`。

`src/deal_pilot/config/nacos/nacos_agent_spec.py`

```python
# 获取单个agent的spec
@func_cache(ttl=nacos_settings.ttl, lazy=True)
async def get_agent_spec(agent_name: str) -> AgentSpec:
    print(f"--> 真正执行了 get_agent_spec({agent_name})")
    access_token = await get_access_token()

    # 请求nacos的API接口，获取agent的spec配置
    async with httpx.AsyncClient(
        base_url=nacos_settings.server_address, headers={"accessToken": access_token}
    ) as client:
        response = await client.get(
            "/nacos/v3/client/ai/agentspecs",
            params={
                "namespaceId": nacos_settings.namespace_id,
                "name": agent_name,
                "label": "production",
            },
        )
        response = response.json()
        if response["code"] != 0:
            return AgentSpec()

    # 构造agent spec的类型
    response = response["data"]
    config = response.get("content", {})
    config = json.loads(config)

    if "mcps" in config:
        config["mcps"] = await get_mcps(config["mcps"])

    system_prompt = (
        response.get("resource", {})
        .get(f"instruction_{agent_name}/AGENTS__MD", {})
        .get("content", "")
    )
    config["system_prompt"] = system_prompt
    print(config)
    return AgentSpec.model_validate(config)
```

测试点：

- 命中与参数键：同参数只算一次，不同参数各算一次，关键字参数参与缓存键
- 缓存按函数隔离；`None` 结果也会被缓存
- 首次计算抛异常不写缓存，下次可重试成功
- `ttl` 过期后刷新；`lazy=False` 时先刷新再返回
- 并发首次调用、并发过期刷新都只执行一次
- `lazy=True` 时立即返回旧值，且后台只起一个刷新
- 同步函数与异步函数两条分支都要覆盖
