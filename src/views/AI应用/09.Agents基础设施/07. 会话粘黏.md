# 会话粘黏
## 当前问题
目前虽然已经搭建网关了，但是存在一个生产级别的大问题，关系到企业的费用开销。

**复现步骤**
1. 在agentServer的同一个线程下，发送三个消息：
```text
1*2等于几，请直接回答
```

2. 回到LiteLLM网关log查看，发现每次的credential都是随机分发的。
```
第一次请求  credential1
第二次请求  credential2
第三次请求  credential1
```

这个问题就导致了每个请求的credential都是随机的，模型的k-v缓存就爆炸了。

## 解决方案
LiteLLM提供了会话粘黏的功能，可以解决这个问题。
1. litellm-config.yaml中添加会话粘黏配置：
该配置代表每次路由前都做一次插件，启动会话粘黏功能。
```yaml
router_settings:
  optional_pre_call_checks:
    - session_affinity
```
2. 传递给网关会话id，让网关知道当前请求的会话。
光配置了会话粘连仍然不够，是因为网关还需要知道当前会话的id是谁。

当请求头携带x-litellm-session-id:xxxx时，网关会将该会话的credential固定到该模型。
```sh
x-litellm-session-id: xxxx
```

那么可以在agent创建模型的时候，配置一个默认的头信息。
```python
model=init_chat_model({
    "default_headers": {
        "x-litellm-session-id": "thread_id"
    }
})
```

配置完之后，在一个线程中再次测试，观察网关就会将三个请求合并为一次会话了。
```text
这是一个测试语句，返回ok即可
```

## 核心改动
1. create_model.py中添加默认头信息
2. 封装一个`get_thread_id`函数，用来获取当前线程的id
3. 将`get_thread_id`函数应用到create_model.py和trace_wrapper.py中

```python [src/deal_pilot/utils/shared.py]
from langgraph.config import get_config


def get_thread_id():
    config = get_config()
    if not config:
        return None
    return config.get("configurable", {}).get("thread_id", None)
```

```python [src/deal_pilot/utils/create_model.py]
from langchain.chat_models import init_chat_model
from deal_pilot.config.openai_settings import openai_settings
from deal_pilot.utils.shared import get_thread_id


def create_model(**kwargs):
    # 不允许用户自定义 model_provider
    kwargs.pop("model_provider", None)  # 删除 model_provider 字段
    thinking = kwargs.get("thinking", True)
    kwargs.pop("thinking", None)
    kwargs.pop("extra_body", None)
    # 初始化模型配置
    config = {
        "model": openai_settings.default_model,
        "model_provider": "openai_reasoning",
        "extra_body": {"enable_thinking": thinking},
    }
    # 获取当前线程id
    thread_id = get_thread_id()
    if thread_id:
        config["default_headers"] = {"x-litellm-session-id": thread_id}

    config.update(kwargs)
    model = init_chat_model(**config)
    return model
```

```python [src/deal_pilot/utils/trace_wrapper.py]
from langfuse.langchain import CallbackHandler
from langchain_core.runnables import RunnableConfig
from langfuse.types import TraceContext
from langgraph_sdk.runtime import ServerRuntime
from langfuse import propagate_attributes
from contextlib import asynccontextmanager
from deal_pilot.utils.shared import get_thread_id


def trace_wrapper(agent_factory):
    @asynccontextmanager
    async def _trace(config: RunnableConfig, runtime: ServerRuntime):
        metadata = config.get("metadata", {})
        trace_id: str = metadata.get("trace_id", "")
        parent_span_id: str = metadata.get("parent_span_id", "")
        trace_context: TraceContext | None = None
        if trace_id and parent_span_id:
            trace_context = {"trace_id": trace_id, "parent_span_id": parent_span_id}

        trace_handler = CallbackHandler(trace_context=trace_context)
        agent = await agent_factory()
        thread_id = get_thread_id()
        assert runtime.user is not None
        agent = agent.with_config(
            callbacks=[trace_handler],
            metadata={
                "langfuse_session_id": thread_id,
                "langfuse_user_id": runtime.user.identity,
            },
        )

        env = metadata.get("trace_environment", "")
        if env:
            with propagate_attributes(environment=env):
                yield agent
        else:
            yield agent

    return _trace
```
