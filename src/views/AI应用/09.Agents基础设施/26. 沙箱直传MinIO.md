# 沙箱直传MinIO
本节课只测试是否可以在沙箱内上传文件到MinIO对象存储。

梳理下现在已经有的基础设施:
```
Agent
沙箱sandbox
对象存储MinIO
```

我们目的是: 让沙箱内执行命令，生成的产物由沙箱上传到MinIO。

上节课已经实现了自己定义的MinIO SDK，我们需要把这个工具放到沙箱内，让沙箱具有上传对象存储的能力。

## 落地步骤
修改沙箱的dockerfile
```dockerfile
FROM node:24-bookworm AS node

FROM python:3.13-bookworm

# 从同为 Debian Bookworm 的官方镜像复制 Node.js 和 npm。
COPY --from=node /usr/local/bin/node /usr/local/bin/node
COPY --from=node /usr/local/lib/node_modules/npm /usr/local/lib/node_modules/npm
RUN ln -s ../lib/node_modules/npm/bin/npm-cli.js /usr/local/bin/npm \
    && ln -s ../lib/node_modules/npm/bin/npx-cli.js /usr/local/bin/npx

COPY --from=ghcr.io/astral-sh/uv:0.12.20 /uv /uvx /usr/local/bin/

# uv 使用阿里云 PyPI；npm 安装 pnpm、pnpm 安装项目依赖时使用 npmmirror。
ENV UV_DEFAULT_INDEX=https://mirrors.aliyun.com/pypi/simple/ \
    NPM_CONFIG_REGISTRY=https://registry.npmmirror.com/ \
    PNPM_CONFIG_REGISTRY=https://registry.npmmirror.com/

RUN npm install --global pnpm@12 \
    && python3 --version \
    && uv --version \
    && node --version \
    && pnpm --version \
    && test "$(pnpm config get registry)" = "https://registry.npmmirror.com/"

# 构建上下文使用项目根目录：docker build -f docker/sandbox/Dockerfile .
WORKDIR /sandbox_utils
RUN uv init --bare --name sandbox-utils --python 3.13
RUN uv add "aiobotocore==3.9.2"

COPY src/deal_pilot/utils/minio.py /sandbox_utils/minio.py
RUN uv run --locked python -c "from minio import MinIO"

WORKDIR /root/workspace
```

重新构建沙箱镜像
```sh
docker build -t opensandbox-python-node:1.0 -f docker/sandbox/Dockerfile .
```

重启容器
```sh
docker run -d --name sandbox-test opensandbox-python-node:1.0 tail -f /dev/null
```

进入容器验证
```sh
docker exec -it sandbox-test bash
```

```
cd /sandbox_utils
cat minio.py
```

## 测试上传到MinIO对象存储
```python
from deal_pilot.backends.sandbox_backend import SandboxBackend

backend = SandboxBackend(lambda:"abc")
```

```python
await backend.awrite("/root/workspace/1.txt", "hello")
```

```python
cmd = """(
cd /sandbox_utils && uv run python - <<'EOF'
from minio import MinIO

async def main():
    client = MinIO(
        endpoint="host.docker.internal:9002",
        access_key="xxx",
        secret_key="xxx",
        secure=False
    )
    bucket_name="agent-artifacts"
    await client.create_bucket(bucket_name)
    await client.upload_file(
        bucket_name=bucket_name,
        filename="/uploads/1.txt",
        source_file="/root/workspace/1.txt"
    )
import asyncio
asyncio.run(main())
print("上传完成")
EOF
)
"""

await backend.aexecute(
    command=cmd
)
```

最后访问MinIO对象存储地址:
```
http://localhost:9002/agent-artifacts/uploads/1.txt
```
