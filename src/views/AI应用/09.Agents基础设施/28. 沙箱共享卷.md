# 沙箱共享卷（笔记）

> 对应课件：《28. 沙箱共享卷.md》。本文按「问题 → 思路 → 落地代码 → 验证 → 排坑」组织，代码均摘自当前工程实际改动。

## 一、要解决的问题

Skill 以前要进入每个用户的专属卷（挂载在 `/root`），会带来四个问题：

1. 有多少个用户，就要重复占用多少份存储空间。
2. 有多少个用户，就要同步多少次 Skill。
3. Skill 变动后，必须重启每个用户的沙箱才能生效，哪怕用户根本没在用沙箱。
4. Agent 执行期间若改动了 Skill，难以跟踪和分析。

本质原因：**"会被所有用户共同读取的数据"和"每个用户私有的数据"混在了同一个卷里**。

![原始状态：每个用户对应一个沙箱，各自的专属卷挂载到 /root](https://zongyan30.github.io/front-assets/agent/sandbox-private-volumes.png)

## 二、解决思路

把两类数据拆开，各自放到合适的卷里，于是出现了"两类沙箱"：

![用户与沙箱一一对应；专属卷挂载到 /root；同一个共享卷在用户沙箱中以只读方式挂载到 /shared，在共享沙箱中以读写方式挂载到 /shared](https://zongyan30.github.io/front-assets/agent/sandbox-shared-volumes.png)

|              | 用户沙箱（专有）                | 共享沙箱                     |
| ------------ | ----------------------- | ------------------------ |
| store 中的 key | 用户 id                   | 固定值 `sandbox-shared`     |
| `/root`      | 挂**专属卷**（可写，卷名 = 用户 id） | 不挂                       |
| `/shared`    | 挂**共享卷**（**只读**）        | 挂**共享卷**（**可写**）         |
| 谁来创建         | 对话中 Agent 调用沙箱工具时       | 加载 agent spec 同步 Skill 时 |
| 数量           | 每用户 1 个                 | 全局 1 个                   |

关键设计：**同一个共享卷 `sandbox-shared-data`，在两类沙箱里以不同权限挂载**——

- 共享沙箱以**读写**方式挂 `/shared`：它是唯一有资格写共享卷的一方，负责把 Skill 写进去；
- 用户沙箱以**只读**方式挂 `/shared`：所有用户都能读到同一份 Skill，但 Agent 永远改不了它。

Skill 的流转链路：

```
Nacos（skill 的 zip 包）
   │  加载 agent spec 时触发
   ▼
共享沙箱（rw）──写入──▶ 共享卷 sandbox-shared-data：/shared/skills/<agent_name>/
   │                          │
   │                          └──只读挂载──▶ 每个用户沙箱的 /shared（Agent 读 Skill 用）
   ▼
用户沙箱 /root（rw）── 用户私有工作区，与 Skill 无关
```

这样四个问题全部消解：共享数据只占一份空间；Skill 只同步一次；Skill 变动只需通过共享沙箱写入；用户侧只读、不可能被 Agent 污染。

## 三、落地步骤

改动分五步，自底向上：

1. **泛化卷挂载**：`utils/sandbox.py` 引入 `VolumeConfig` 抽象，`_create` 从"写死挂一个 `/root` 卷"改为"按传入的卷配置列表挂载"，`get_sandbox`/`enter_sandbox` 透传该参数；
2. **新增共享沙箱**：固定 key + 共享卷可写挂载到 `/shared`，即 `get_shared_sandbox`；
3. **用户沙箱后端挂双卷**：`SandboxBackend` 声明自己的卷配置——`/root` 专属卷可写 + `/shared` 共享卷只读；
4. **打通 Skill 同步链路**：新增 `nacos_skills.py` 从 Nacos 拉 skill 的 zip、写进共享沙箱并解压；`get_agent_spec` 加载 spec 时调用它；同时把 `skills` 字段从 `AgentSpec` 和 `create_deep_agent` 的参数中**移除**（Skill 不再进 Agent 本体，改由沙箱 `/shared` 提供）；
5. **镜像支持解压**：`Dockerfile` 安装 `unzip`，供共享沙箱解压 skill 的 zip 包。

```python
async def _create(
    *,
    sandbox_config: OpenSandboxConfig,
    connection_config: ConnectionConfig,
    volume_configs: list[VolumeConfig] | None = None,
):

    # 创建卷柜
    if volume_configs is None:
        volume_configs = []

    volumes = [
        Volume(
            name=v.name,
            mountPath=v.mount_path,
            readOnly=v.readonly,
            pvc=PVC(
                claimName=v.name,
                createIfNotExists=True,
                deleteOnSandboxTermination=False,
            ),
        )
        for v in volume_configs
    ]

    # 创建沙箱
    sandbox = await Sandbox.create(
        # 镜像
        image=sandbox_config.image,
        # 连接配置
        connection_config=connection_config,
        # 超时时间
        timeout=timedelta(seconds=sandbox_config.timeout_seconds),
        # 就绪超时时间
        ready_timeout=timedelta(seconds=sandbox_config.ready_timeout_seconds),
        # 卷柜
        volumes=volumes,
    )

    return sandbox
```

```python
async def get_sandbox(
    key: str | None = None,
    store: BaseStore | None = None,
    volume_configs: list[VolumeConfig] | None = None,
):
    # 参数归一化
    if key is None:
        key = str(uuid.uuid4())
    if store is None:
        try:
            runtime = get_runtime()
            store = runtime.store
            if store is None:
                store = _MEMORY_STORE
        except Exception:
            store = _MEMORY_STORE

    # 加锁控制并发,有就取出来,没有就默认创建一个锁
    lock = _lockMap.setdefault(key, asyncio.Lock())

    async with lock:
        sandbox_config = await get_config("sandbox_config", OpenSandboxConfig)
        connection_config = ConnectionConfig(
            domain=sandbox_settings.domain,
            api_key=sandbox_settings.api_key,
            use_server_proxy=True,
        )

        sandbox = await _connect(
            connection_config=connection_config,
            key=key,
            store=store,
        )

        if not sandbox:
            sandbox = await _create(
                sandbox_config=sandbox_config,
                connection_config=connection_config,
                volume_configs=volume_configs,
            )
            # 把 sandbox_id 写回 store，供后续 _connect 复用
            await store.aput(_NAMESPACE, key, {"sandbox_id": sandbox.id})

        return sandbox
```

```python
# 获取共享沙箱
async def get_shared_sandbox(store: BaseStore | None = None) -> Sandbox:
    return await get_sandbox(
        SHARED_SANDBOX_KEY,
        store,
        [
            VolumeConfig(
                name=SHARED_VOLUME_NAME,
                mount_path="/shared",
                readonly=False,
            )
        ],
    )
```

:::

注意两个易错点：

- **挂载只在创建沙箱时生效**。`_connect` 复用旧容器不会重新挂卷，所以卷配置只在 `_create` 路径上有意义；如果改了卷配置，必须让旧沙箱过期/销毁后重建才生效。
- `PVC(deleteOnSandboxTermination=False)`：沙箱销毁时卷保留，所以用户数据（`/root`）和共享数据都能跨沙箱重建存活。

### 步骤 3：`backends/sandbox_backend.py`

用户沙箱的卷声明集中在 `_get_volume_configs`，三个异步方法（执行命令/上传/下载）都传给它：

```python
from deal_pilot.utils.sandbox import SHARED_VOLUME_NAME, VolumeConfig, enter_sandbox

    # 获取卷柜配置
    def _get_volume_configs(self) -> list[VolumeConfig]:
        return [
            VolumeConfig(
                mount_path="/root", readonly=False, name=self.id.replace("_", "-")
            ),
            VolumeConfig(mount_path="/shared", readonly=True, name=SHARED_VOLUME_NAME),
        ]

    async def aexecute(self, command, *, timeout=None):
        # ...参数归一...

        # 获取沙箱
        async with enter_sandbox(
            self.id, volume_configs=self._get_volume_configs()
        ) as sandbox:
            execution = await sandbox.commands.run(
                command, opts=RunCommandOpts(timeout=timedelta(seconds=timeout))
            )
        # ...
```

`self.id` 是当前用户 id；用户 id 里的下划线换成横线作为专属卷名（Docker 卷名不支持下划线）。`aupload_files` / `adownload_files` 中的 `enter_sandbox` 调用同样改为传入 `volume_configs=self._get_volume_configs()`。

### 步骤 4：Skill 同步链路

::: code-group

```python
import asyncio
import httpx
from opensandbox import Sandbox
from deal_pilot.config.nacos_settings import nacos_settings
from deal_pilot.config.nacos.nacos_access_token import get_access_token
from deal_pilot.utils.sandbox import get_shared_sandbox


# 保存单个skill
async def _save_skill(
    *, skill_name: str, sandbox: Sandbox, zip_path: str, skill_dir: str
):
    # 1. 从nacos获取skill的zip文件,上传到共享沙箱skill的zip目录
    access_token = await get_access_token()

    async with httpx.AsyncClient(
        base_url=nacos_settings.server_address, headers={"accessToken": access_token}
    ) as client:
        response = await client.get(
            "/nacos/v3/client/ai/skills",
            params={
                "namespaceId": nacos_settings.namespace_id,
                "name": skill_name,
                "label": "production",
            },
        )
    zip_bytes = response.content
    await sandbox.files.write_file(zip_path, zip_bytes)
    # 2. 解压zip到共享沙箱的skill目录
    result = await sandbox.commands.run(
        f"mkdir -p {skill_dir} && " f"unzip -o {zip_path} -d {skill_dir}"
    )
    if result.exit_code != 0:
        raise RuntimeError(f"解压技能 {skill_name} 失败: {result.error}")
    print(len(zip_bytes))


# 保存skills到共享沙箱
async def save_skills_to_shared_sandbox(
    agent_name: str, skill_names: list[str] | None = None
):
    """保存skills到共享沙箱"""

    if skill_names is None:
        skill_names = []

    shared_sandbox = await get_shared_sandbox()
    skill_dir = f"/shared/skills/{agent_name}"

    await shared_sandbox.commands.run("rm -rf {skill_dir}")
    await asyncio.gather(
        *[
            _save_skill(
                skill_name=skill_name,
                sandbox=shared_sandbox,
                zip_path=f"/shared/skill_zips/{agent_name}/{skill_name}.zip",
                skill_dir=skill_dir,
            )
            for skill_name in skill_names
        ]
    )
```

```python
from deal_pilot.config.nacos.nacos_skills import save_skills_to_shared_sandbox

    # 挂载skills到共享沙箱
    skills = config.get("skills", [])
    await save_skills_to_shared_sandbox(agent_name=agent_name, skill_names=skills)
```

:::

目录约定：zip 包先写到 `/shared/skill_zips/<agent_name>/`，解压产物放 `/shared/skills/<agent_name>/`。用户沙箱侧 Agent 只需要读 `/shared/skills/<agent_name>/`。

**同时移除 skills 进 Agent 本体的旧链路**（Skill 改由沙箱 `/shared` 提供）：

- `nacos_schemas.py`：`AgentSpec` 删除 `skills: list[str]` 字段；
- `agent_factory.py` / `main.py` / `web.py`：`create_agent` 及各工厂实现删除 `skills` 形参，不再传给 `create_deep_agent`。
