# 创建和连接沙箱
## 解决方案
回顾一下沙箱特点:
1. 沙箱具有存活时间
2. 持久化数据

阿里云沙箱:
* 通过sdk创建/连接已有沙箱，设置沙箱存活时间
* 通过oss存储数据，实现持久化

开源沙箱：
* 通过sdk在docker新建容器，来创建/连接已有沙箱，设置沙箱存活时间
* 通过docker卷柜，来持久化数据



## 落地方案
1. 新建`sandbox.py`模块，内置创建、连接沙箱。

2. 使用store记录每个用户自己的沙箱信息，一个用户对应一个沙箱(id和卷柜)。

* 使用`user_id`作为key，value是用户自己沙箱的信息。
* 将记录的数据存储在store。
```json
"key(user_id)":{
    "sandbox_id": "fasfdgfg",
    "volume_name": "testVolume",
}
```

3. 准备创建和连接沙箱两个函数，内部通过openSandbox SDK来连接。
3.1 创建沙箱
从store中取卷柜是否已经创建，存在-使用当前卷柜 不存在-创建新卷柜

```python
# 创建沙箱
async def _create(
    *,
    sandbox_config: OpenSandboxConfig,
    connection_config: ConnectionConfig,
    key: str,
    store: BaseStore,
):

    # 创建卷柜
    v_name = await _get_store(key, store, "volume")
    if v_name is None:
        v_name = str(uuid.uuid4()).replace("-", "")

    v = Volume(
        name=v_name,
        pvc=PVC(
            claimName=v_name, createIfNotExists=True, deleteOnSandboxTermination=False
        ),
        mountPath="/root",
    )

    # 创建沙箱
    sandbox = await Sandbox.create(
        # 镜像
        image=sandbox_config.image,
        # 连接配置
        connection_config=connection_config,
        # 超时时间
        timeout=timedelta(seconds=sandbox_config.timeout_seconds),
        # 就绪超时时间
        ready_timeout=timedelta(seconds=sandbox_config.ready_timeout_seconds),
        # 卷柜
        volumes=[v],
    )

    await store.aput(_NAMESPACE, key, {"sandbox_id": sandbox.id, "volume": v_name})
    return sandbox
```

`_get_store` 是读取 store 的小工具（取不到就返回 `None`）：

```python
async def _get_store(key: str, store: BaseStore, field_name: str) -> str | None:
    dict = await store.aget(_NAMESPACE, key)
    if dict is None:
        return None
    return dict.value.get(field_name)
```

要点：`deleteOnSandboxTermination=False` 保证沙箱销毁后卷柜还在（持久化）；创建成功后把 `sandbox_id` 和 `volume` 一起写回 store。
3.2 连接沙箱
从store中取沙箱id是否已经存在，存在-使用当前沙箱id 不存在-创建新沙箱id

```python
# 连接沙箱
async def _connect(
    *,
    connection_config: ConnectionConfig,
    key: str,
    store: BaseStore,
) -> Sandbox | None:
    # 从store中取出sandbox_id
    sandbox_id = await _get_store(key, store, "sandbox_id")
    if sandbox_id is None:
        return None

    # 连接沙箱（沙箱有可能已经过期了，连接不上就会报错）
    try:
        sandbox = await Sandbox.connect(
            sandbox_id=sandbox_id, connection_config=connection_config
        )
        return sandbox
    except SandboxApiException as exc:
        if exc.status_code == 404:
            return None
        else:
            raise
```

要点：沙箱有存活时间，过期后连接会报 404，此时返回 `None` 交给上层去新建；其他异常照常抛出。
4. 设计`get_sandbox(key,store)`函数

* 先做参数归一化处理，确保都具备默认值
* 先连接沙箱，连接不上再创建沙箱

```python
# 获取沙箱
async def get_sandbox(key: str | None = None, store: BaseStore | None = None):
    # 参数归一化
    if key is None:
        key = str(uuid.uuid4())
    if store is None:
        try:
            runtime = get_runtime()
            store = runtime.store
            if store is None:
                store = _MEMORY_STORE
        except Exception:
            store = _MEMORY_STORE

    # 加锁控制并发,有就取出来,没有就默认创建一个锁
    lock = _lockMap.setdefault(key, asyncio.Lock())

    async with lock:
        sandbox_config = await get_config("sandbox_config", OpenSandboxConfig)
        connection_config = ConnectionConfig(
            domain=sandbox_settings.domain,
            api_key=sandbox_settings.api_key,
            use_server_proxy=True,
        )

        sandbox = await _connect(
            connection_config=connection_config,
            key=key,
            store=store,
        )

        if not sandbox:
            sandbox = await _create(
                sandbox_config=sandbox_config,
                connection_config=connection_config,
                key=key,
                store=store,
            )

        return sandbox
```

要点：`key` 为空就随机一个（一次性沙箱）；`store` 为空优先取 langgraph runtime 的 store，取不到退回进程内 `InMemoryStore`；配置从 Nacos 读，连接信息从环境变量读。

5. 连接和创建的时候注意并发锁，。
* 使用`WeakValueDictionary`来记录锁实例，解决并发问题。
* 使用user_id作为key，每个user_id对应一个锁实例。
> 防止用户A和用户B同时请求时，因为用户A先到，锁被占用，导致用户B一直在等待。
```json
{
    "key(user_id)":"锁实例asyncio.lock()" 
}
```
> 这样可以做到用户A发送两次沙箱创建请求，但是第一次上锁了，第二次不会重复创建。

```python
_lockMap: WeakValueDictionary[str, asyncio.Lock] = WeakValueDictionary()  # 并发锁
```

```python
# 加锁控制并发,有就取出来,没有就默认创建一个锁
lock = _lockMap.setdefault(key, asyncio.Lock())

async with lock:
    ...  # 连接 / 创建沙箱
```

用 `WeakValueDictionary` 而不是普通 dict：沙箱销毁、没有强引用后锁会自动被回收，不会无限堆积。

from datetime import timedelta
import uuid
from langgraph.store.base import BaseStore
from langgraph.store.memory import InMemoryStore
from langgraph.runtime import get_runtime
import asyncio
from weakref import WeakValueDictionary
from opensandbox import Sandbox
from opensandbox.config import ConnectionConfig
from deal_pilot.config.nacos.nacos_config import get_config
from deal_pilot.config.nacos.nacos_schemas import OpenSandboxConfig
from deal_pilot.config.sandbox_settings import sandbox_settings
from opensandbox.models import PVC, Volume
from opensandbox.exceptions import SandboxApiException


_lockMap: WeakValueDictionary[str, asyncio.Lock] = WeakValueDictionary()  # 并发锁
_MEMORY_STORE = InMemoryStore()  # 存储store

    return dict.value.get(field_name)

    v_name = await _get_store(key, store, "volume")

    sandbox = await Sandbox.create(
