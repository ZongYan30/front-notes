本节课先解决追加沙箱提示词的问题

## 解决方案

1. nacos配置沙箱prompt
2. agent spec追加`link_prompts`配置
3. 代码中将nacos配置的prompt拉取下来，追加到系统提示词之后即可。


## 落地步骤

1. nacos中新增沙箱附加提示词,提交发布，设置label为production
   ```text
   ## 沙箱说明

   你通过沙箱后端提供的工具操作文件和执行命令。请遵守以下环境约定与工作规范。

   一、沙箱环境
   - 你操作的是独立的 Linux 沙箱，基于 Debian Bookworm，以 root 用户运行。沙箱中的路径不是用户本机的路径。
   - 镜像预装 Python 3.13、uv 0.12.20、Node.js 24、npm 和 pnpm 12，可使用 Python、Shell 或 Node.js 完成任务。
   - uv 默认使用阿里云 PyPI 镜像，npm 和 pnpm 默认使用 npmmirror。
   - 沙箱的默认工作目录是 /root/workspace，每一次读写文件、运行命令默认均在此目录。

   二、持久化范围
   - /root 是持久化卷的挂载点，其目录及子目录中的文件会保留。沙箱过期或重建后，重新挂载同一个卷即可继续使用这些文件。
   - /root/workspace 位于持久化范围内，任务代码、输入数据、中间成果、最终产物和恢复任务所需的记录都应放在这里。
   - /root 之外的运行期新增或修改内容不会持久化。例如 /tmp、/var/tmp、/usr/local、/opt 中临时写入的文件或安装的依赖，都会随沙箱销毁而丢失。新沙箱只保留镜像原本提供的内容。
   - 持久化只保留文件，不保留运行中的进程、内存变量、后台服务、当前 Shell 的目录和临时 export 的环境变量。沙箱重建后，需要根据保存的文件重新启动程序和恢复工作。
   - 持久化不等于备份：删除或覆盖 /root 中的文件也会作用于持久化卷，不要指望重建沙箱能撤销这些操作。

   三、工作目录与文件规范
   - 所有正式工作都在 /root/workspace 下进行。为不同任务建立独立子目录，例如 /root/workspace/<task-name>，避免相互覆盖。
   - 开始任务前先查看已有文件；继续已有任务时优先使用原任务目录，不要清空工作区或重复生成覆盖已有成果。
   - 每次执行命令都显式进入任务目录，例如：cd /root/workspace/<task-name> && python main.py。不要假设上一次命令中的 cd、export 或虚拟环境激活状态会延续到下一次调用。
   - 文件工具优先使用绝对路径。命令中的路径包含空格或特殊字符时必须正确引用。
   - 仅用于本次执行且可以重新生成的临时文件可放在 /tmp；需要保留的文件必须在任务结束前写入 /root/workspace 下。
   - 不要将指向持久化目录外部的符号链接当作持久化文件：链接本身留在 /root 中，并不代表它指向的内容会保留。

   四、依赖与执行规范
   - Python 依赖优先通过 uv 安装到任务目录内的 .venv，使用 uv run 或 .venv/bin/python 执行；保存 pyproject.toml、uv.lock 或 requirements.txt，以便必要时重建环境。
   - Node.js 依赖安装在任务目录内，保存 package.json 和对应的锁文件，优先使用 pnpm 管理。
   - 不要依赖全局安装或系统目录修改来保存任务环境。确需使用时，要记录安装步骤；沙箱重建后，这些运行期变更可能需要重新执行。
   - 长任务应分阶段将进度、必要数据和中间结果写入任务目录。恢复任务时先检查文件和依赖，再判断是否需要重启程序，不要假设旧进程仍在运行。
   - 根据命令退出码和实际输出判断执行是否成功，生成文件后检查其是否存在、内容是否符合要求。不要将“命令已提交”当作“任务已完成”。
   - 删除或覆盖文件前确认目标路径与任务范围，避免误删其他任务文件。
   ```

4. 封装获取prompt的函数(参考获取mcp的函数)
   ```python
   from deal_pilot.config.nacos.nacos_schemas import MCPServerConfig
   from deal_pilot.config.nacos.nacos_access_token import get_access_token
   from deal_pilot.config.nacos_settings import nacos_settings
   from deal_pilot.utils.func_tools import func_cache
   import httpx
   import asyncio


   # 获得单个prompt配置
   @func_cache(ttl=nacos_settings.ttl, lazy=True)
   async def get_prompt(prompt_name: str) -> str:
       access_token = await get_access_token()

       # 从nacos获取单个mcp配置
       async with httpx.AsyncClient(
           base_url=nacos_settings.server_address, headers={"accessToken": access_token}
       ) as client:
           response = await client.get(
               "/nacos/v3/client/ai/prompt",
               params={
                   "namespaceId": nacos_settings.namespace_id,
                   "promptKey": prompt_name,
                   "label": "production",
               },
           )
           response = response.json()
           if response["code"] != 0:
               return ""

       response = response["data"]
       return response["template"]


   # 获得所有promp配置
   async def get_prompts(prompts_names: list[str]) -> str:
       tasks = [get_prompt(prompt_name) for prompt_name in prompts_names]  # 并发所有异步
       prompts = await asyncio.gather(*tasks)  # 类似Promise.all
       return "\n\n".join(prompts)


   if __name__ == "__main__":
       # 测试缓存装饰器是否生效
       async def main():
           res = await get_prompts(["sandbox"])
           import rich

           rich.print(res)

       asyncio.run(main())
   ```
5. 获取agent_spec时，将沙箱提示词拼接到系统提示词中
   ```python
   from deal_pilot.config.nacos.nacos_prompts import get_prompts
   from deal_pilot.config.nacos.nacos_schemas import AgentSpec
   from deal_pilot.config.nacos.nacos_access_token import get_access_token
   from deal_pilot.config.nacos_settings import nacos_settings
   from deal_pilot.config.nacos.nacos_mcp import get_mcps
   from deal_pilot.utils.func_tools import func_cache
   import asyncio
   import json
   import httpx


   # 获取单个agent的spec


   @func_cache(ttl=nacos_settings.ttl, lazy=True)
   async def get_agent_spec(agent_name: str) -> AgentSpec:
       # print(f"--> 真正执行了 get_agent_spec({agent_name})")
       access_token = await get_access_token()

       # 请求nacos的API接口，获取agent的spec配置
       async with httpx.AsyncClient(
           base_url=nacos_settings.server_address, headers={"accessToken": access_token}
       ) as client:
           response = await client.get(
               "/nacos/v3/client/ai/agentspecs",
               params={
                   "namespaceId": nacos_settings.namespace_id,
                   "name": agent_name,
                   "label": "production",
               },
           )
           response = response.json()
           if response["code"] != 0:
               return AgentSpec(name=agent_name)

       # 构造agent spec的类型
       response = response["data"]
       config = response.get("content", {})
       config = json.loads(config)

       if "mcps" in config:
           config["mcps"] = await get_mcps(config["mcps"])

       # 获取系统提示词
       system_prompt = (
           response.get("resource", {})
           .get(f"instruction_{agent_name}/AGENTS__MD", {})
           .get("content", "")
       )

       # 获取沙箱提示词
       link_prompts = config.get("link_prompts", [])
       link_prompts_content = await get_prompts(link_prompts)

       # 拼接系统提示词和沙箱提示词
       config["system_prompt"] = system_prompt + "\n\n" + link_prompts_content
       config["name"] = agent_name
       print(config)
       return AgentSpec.model_validate(config)


   if __name__ == "__main__":
       # 测试缓存装饰器是否生效
       async def main():
           await get_agent_spec("main_agent")

       asyncio.run(main())
   ```

   ```python
   from deal_pilot.agents.agent_factory import AgentFactory
   from deal_pilot.tools import get_current_time, ask_user_question
   from deal_pilot.utils.create_model import create_model
   from deepagents import create_deep_agent

   from deal_pilot.utils.trace_wrapper import trace_wrapper
   from deal_pilot.utils.get_prompt import get_prompt
   from deal_pilot.middlewares.link_prompt_middleware import create_prompt_link_middleware
   from deal_pilot.agents.main_agent_state import MainAgentState
   from deal_pilot.middlewares.turn_summary import turn_summary
   from typing import Any
   from collections.abc import Sequence
   from langchain.tools import BaseTool
   from langgraph.graph.state import Runnable
   from deal_pilot.backends.sandbox_backend import SandboxBackend


   # 创建main agent工厂
   class MainAgentFactory(AgentFactory):
       @property
       def name(self) -> str:
           return "main_agent"

       async def create_agent(
           self,
           *,
           model: Any,
           system_prompt: str,
           tools: Sequence[BaseTool],
           subagents: list[dict],
           skills: list[str],
       ) -> Runnable:
           agent = create_deep_agent(
               model=model,
               system_prompt=system_prompt,
               tools=tools,

   main_agent_factory = MainAgentFactory()
   factory = main_agent_factory.factory
   factory_with_trace = trace_wrapper(factory)
   ```

> 要点：
>
> - 只贴了 `docker-compose.yml` 的 `nacos` 服务段，本次改动仅为 `volumes` 末尾新增的 bind 挂载（含注释共 6 行）。
> - `plugin-states.json` 只读挂载到容器内 `/home/nacos/data/plugin/plugin-states.json`，改本地 JSON 后重启 Nacos 生效。
> - `create_host_path: false`：宿主机上该文件必须真实存在，路径写错会直接报错，而不是静默创建一个空目录。
> - `visibility:nacos: false` 禁用了 nacos 的可见性插件，重启后到控制台「插件中心」确认其状态为禁用，普通用户就看不到 prompt 管理入口，绕开产品漏掉的权限开关。
