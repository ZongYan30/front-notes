## 安装环境

1. 覆盖 `docker-compose.yml` 文件（新增 `shared-minio` 服务与数据卷）

   ```yaml
     # 共享对象存储，用于保存 Agent 生成的产物、用户上传的文件
     shared-minio:
       image: cgr.dev/chainguard/minio
       restart: always
       entrypoint: sh
       command: -c 'minio server --address ":9000" --console-address ":9001" /data'
       environment:
         MINIO_ROOT_USER: root
         MINIO_ROOT_PASSWORD: "12345678"
         MINIO_BROWSER_REDIRECT_URL: http://localhost:9003
       ports:
         - "9002:9000" # 对象存储 API
         - "9003:9001" # 管理控制台
       volumes:
         - shared_minio_data:/data
       healthcheck:
         test: ["CMD", "mc", "ready", "local"]
         interval: 1s
         timeout: 5s
         retries: 5
         start_period: 1s
   ```

   ```yaml
   volumes:
     # ……原有卷声明保持不变……
     shared_minio_data:
   ```

2. 运行 启动服务

   ```sh
   docker compose up -d shared-minio
   ```

- **Shared MinIO（共享对象存储）**

  管理后台：http://localhost:9003

  账号：root

  密码：12345678

  宿主机访问 API：http://localhost:9002

## 生成专用凭据

### 安装 MinIO Client（mc）

`mc` 是 MinIO 官方的命令行管理工具，独立于 Python 的 `minio` SDK。

[MinIO Client 下载页面](https://min.io/download#/windows) 下载

windows下载
```sh
Invoke-WebRequest -Uri "https://dl.min.io/aistor/mc/release/windows-amd64/mc.exe" -OutFile "mc.exe"
```
验证安装
```sh
mc.exe --version
```

### 保存管理员连接

```bash
mc alias set shared http://localhost:9002 root 12345678
```

| 参数 | 含义 |
|---|---|
| `mc alias set` | 保存或更新本机连接配置 |
| `shared` | 自定义连接别名，后续命令使用它找到连接 |
| `http://localhost:9002` | Shared MinIO 的对象 API 地址 |
| `root` | 当前 Compose 中的管理员 Access Key |
| `12345678` | 当前 Compose 中的管理员 Secret Key |

### 准备专用权限策略

将 `resource/minio-policy.json` 复制到你的工程
目录:
```sh
工程根目录/
└── resource/
    └── minio-policy.json
```
开启权限策略(类似阿里云的对象存储)
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["*"],
      "Resource": ["*"]
    }
  ]
}

```

### 自动生成专用凭据

```text
mc admin user svcacct add --policy resource/minio-policy.json shared root
```

1. 将凭证保存到环境变量

   ```sh
   # MinIO
   MINIO_ACCESS_KEY = "TCO4JUIEHL29WLST736X"
   MINIO_SECRET_KEY = "bDwA9Ycp+IyulPldx5ZTi+ZPUW+k4t1gS+fmRewY"
   MINIO_ENDPOINT = "localhost:9002"
   MINIO_SECURE = false
   ```
2. 新增`minio_settings.py`

   ```python
   from deal_pilot.config.base_settings import BaseSettingsWithEnv


   class MinioSettings(BaseSettingsWithEnv):
       # MinIO 访问密钥。
       access_key: str = ""
       # MinIO 秘密密钥。
       secret_key: str = ""
       # MinIO API 地址，不包含协议前缀。
       endpoint: str = "localhost:9002"
       # 是否使用 HTTPS 连接。
       secure: bool = False

       model_config = {"env_prefix": "MINIO_"}


   minio_settings = MinioSettings()
   ```



### 查看和撤销专用凭据

由管理员列出 root 下的服务账号：

```bash
mc admin user svcacct ls shared root
```

如果需要删除凭据，将下面的占位值替换为实际 Access Key：

```bash
mc admin user svcacct rm shared '<实际生成的 Access Key>'
```
