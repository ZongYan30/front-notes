# AI 资产注册与治理

目前虽然已经有了网关和观测平台，但还有诸多问题没有解决：

- Skill 在哪里管理？
- Prompt 在哪里管理？
- MCP 在哪里管理？
- Agent 在哪里配置？
- ...

以上都是 Agent 运行期间所需要的重要资产。

对这些资产的管理称之为：AI Registry（AI 注册中心，或称之为 AI 资产注册与治理）

目前此类产品的选择主要有两个：

- LangSmith Context Hub
- **Nacos**

## 安装 Nacos
`docker-compose.yml`新增:
```yaml
  nacos:
    image: nacos/nacos-server:v3.2.4-slim
    restart: always
    environment:
      MODE: standalone
      FUNCTION_MODE: all
      NACOS_AUTH_ENABLE: "true"
      NACOS_AUTH_TOKEN: RiVYR9ZY5TKK7gg6089izg65CfwNN3v9h8zemw0OgvnRJsR2CINORJ5FTTpuOYrL
      NACOS_AUTH_IDENTITY_KEY: serverIdentity
      NACOS_AUTH_IDENTITY_VALUE: a820b4504731b71773ba2e711eb09496e8456ea4321c7856
    ports:
      - "127.0.0.1:8080:8080" # 控制台
      - "127.0.0.1:8848:8848" # HTTP 客户端 API
      - "127.0.0.1:9848:9848" # gRPC 客户端通信
    volumes:
      - type: volume
        source: nacos_data
        target: /home/nacos/data
        volume:
          nocopy: true
      - nacos_logs:/home/nacos/logs
```
卷柜新增
```yaml
volumes:
  nacos_data:
  nacos_logs:
```

启动Nacos
```sh
docker compose up -d nacos
```
