# Matplotlib 交互组件

Matplotlib 自带一套基于 `matplotlib.widgets` 的交互式组件，可以直接在图表中添加滑块、按钮、复选框、单选按钮和文本框等控件，让静态图表具备交互能力。

本节介绍如何将这些组件嵌入图表，并通过回调函数响应用户操作。

## 环境准备

安装 Matplotlib 和 Jupyter 交互式绘图后端：

```bash
uv add matplotlib ipympl
```

在 Notebook 中启用交互式后端：

```python
%matplotlib widget
```

导入依赖并设置绘图参数：

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.widgets import (
    Button,
    CheckButtons,
    RadioButtons,
    Slider,
    TextBox,
)

plt.rcParams.update({
    "font.sans-serif": ["PingFang SC"],
    "axes.unicode_minus": False,
    "figure.dpi": 100,
})


def reset():
    plt.close("all")
```

Matplotlib 的交互组件本质上也是一个独立的 Axes。通常先通过 `fig.add_axes()` 为组件预留位置，再创建对应的控件并绑定回调函数。

## Slider：滑块

`Slider` 适合让用户通过拖动调整连续数值，例如频率、振幅、透明度或阈值。

基本使用流程：

1. 使用 `fig.add_axes()` 创建滑块所在的 Axes。
2. 创建 `Slider`，设置标签、取值范围和初始值。
3. 编写回调函数，接收滑块当前值。
4. 使用 `on_changed()` 注册回调函数。

### 调整正弦波频率

```python
reset()
fig, ax = plt.subplots(figsize=(8, 4))
fig.subplots_adjust(bottom=0.25)

x = np.linspace(0, 10, 500)
(line,) = ax.plot(x, np.sin(x), lw=2)
ax.set_ylim(-1.5, 1.5)
ax.set_title("拖动滑块调整频率")

slider_ax = fig.add_axes((0.2, 0.1, 0.6, 0.03))
slider = Slider(
    ax=slider_ax,
    label="频率",
    valmin=0.1,
    valmax=5.0,
    valinit=1.0,
    valstep=0.1,
)


def update(freq):
    line.set_ydata(np.sin(freq * x))
    fig.canvas.draw_idle()


slider.on_changed(update)
```

`draw_idle()` 会请求画布在合适的时机重新绘制，适合用于交互回调中，避免频繁操作造成不必要的同步重绘。

### 多个滑块

多个滑块可以分别控制不同参数，从而实现多维度调整：

```python
reset()
fig, ax = plt.subplots(figsize=(8, 5))
fig.subplots_adjust(bottom=0.3)

x = np.linspace(0, 10, 500)
(line,) = ax.plot(x, np.sin(x), lw=2)
ax.set_ylim(-2, 2)

freq_slider_ax = fig.add_axes((0.2, 0.15, 0.6, 0.03))
freq_slider = Slider(
    freq_slider_ax,
    "频率",
    0.1,
    5.0,
    valinit=1.0,
)

amp_slider_ax = fig.add_axes((0.2, 0.1, 0.6, 0.03))
amp_slider = Slider(
    amp_slider_ax,
    "振幅",
    0.1,
    2.0,
    valinit=1.0,
)


def update(_):
    line.set_ydata(
        amp_slider.val * np.sin(freq_slider.val * x)
    )
    fig.canvas.draw_idle()


freq_slider.on_changed(update)
amp_slider.on_changed(update)
```

在回调函数中使用 `slider.val` 获取当前滑块值。两个滑块都绑定同一个 `update()`，任何一个滑块发生变化时都会重新计算曲线。

## Button：按钮

`Button` 适合执行一次性操作，例如重新生成数据、重置参数、清空图表或保存结果。

```python
reset()
fig, ax = plt.subplots(figsize=(8, 4))
fig.subplots_adjust(bottom=0.2)

x = np.linspace(0, 10, 100)
(line,) = ax.plot(
    x,
    np.random.randn(100).cumsum(),
    lw=2,
)
ax.set_title("点击按钮重新生成数据")

button_ax = fig.add_axes((0.4, 0.05, 0.2, 0.075))
button = Button(
    button_ax,
    "重新生成",
    color="lightblue",
    hovercolor="skyblue",
)


def regenerate(event):
    line.set_ydata(np.random.randn(100).cumsum())
    ax.relim()
    ax.autoscale_view()
    fig.canvas.draw_idle()


button.on_clicked(regenerate)
```

按钮回调函数会接收一个事件对象 `event`。如果不需要使用事件信息，可以保留参数但不读取它。

更新随机数据后，调用：

- `ax.relim()`：重新计算数据范围
- `ax.autoscale_view()`：根据新的数据范围调整视图

## CheckButtons：复选框

`CheckButtons` 允许用户同时切换多个独立选项，常用于控制多条曲线、数据系列或图层的显示与隐藏。

```python
reset()
fig, ax = plt.subplots(figsize=(8, 5))
fig.subplots_adjust(left=0.3)

x = np.linspace(0, 10, 200)
lines = {}
colors = ["red", "blue", "green"]
labels = ["sin(x)", "cos(x)", "sin(x)*cos(x)"]
funcs = [
    np.sin,
    np.cos,
    lambda x: np.sin(x) * np.cos(x),
]

for label, color, func in zip(labels, colors, funcs):
    (line,) = ax.plot(
        x,
        func(x),
        color=color,
        lw=2,
        label=label,
        visible=True,
    )
    lines[label] = line

ax.legend(loc="upper right")
ax.set_title("复选框控制曲线显示")

check_ax = fig.add_axes((0.05, 0.4, 0.15, 0.2))
check = CheckButtons(
    check_ax,
    labels,
    [True, True, True],
)


def toggle(label):
    lines[label].set_visible(
        not lines[label].get_visible()
    )
    fig.canvas.draw_idle()


check.on_clicked(toggle)
```

`CheckButtons` 的回调函数接收被点击选项的标签。通过字典保存标签与曲线对象之间的关系，就可以快速找到需要切换的曲线。

## RadioButtons：单选按钮

`RadioButtons` 用于从一组互斥选项中选择一个，适合切换函数类型、图表类型或数据来源。

```python
reset()
fig, ax = plt.subplots(figsize=(8, 5))
fig.subplots_adjust(left=0.3)

x = np.linspace(0, 10, 200)
(line,) = ax.plot(x, np.sin(x), lw=2, color="royalblue")
ax.set_ylim(-2, 2)
ax.set_title("单选按钮切换函数类型")

radio_ax = fig.add_axes((0.05, 0.4, 0.15, 0.2))
radio = RadioButtons(radio_ax, ("sin", "cos", "tan"))

func_map = {
    "sin": np.sin,
    "cos": np.cos,
    # 缩放正切函数，避免曲线过大
    "tan": lambda x: np.tan(x) * 0.5,
}


def switch(label):
    line.set_ydata(func_map[label](x))
    fig.canvas.draw_idle()


radio.on_clicked(switch)
```

这里使用字典保存选项标签和函数之间的映射。用户选择不同选项时，只需根据标签取出对应函数即可。

需要注意，正切函数存在渐近线。实际绘图时通常需要限制坐标范围，或者对数据进行处理，避免曲线超出可视区域。

## TextBox：文本框

`TextBox` 用于接收用户输入的文本，适合输入精确数值、自定义标签或表达式参数。

```python
reset()
fig, ax = plt.subplots(figsize=(8, 4))
fig.subplots_adjust(bottom=0.2)

x = np.linspace(0, 10, 500)
(line,) = ax.plot(x, np.sin(x), lw=2)
ax.set_ylim(-1.5, 1.5)
ax.set_title("输入频率值后按回车")

text_ax = fig.add_axes((0.2, 0.05, 0.6, 0.06))
text_box = TextBox(
    text_ax,
    "频率",
    initial="1.0",
)


def submit(text):
    try:
        freq = float(text)
        line.set_ydata(np.sin(freq * x))
        fig.canvas.draw_idle()
    except ValueError:
        pass


text_box.on_submit(submit)
```

`on_submit()` 会在用户提交文本时调用回调函数。由于文本框输入的是字符串，因此需要先使用 `float()` 转换为数值。

这里通过 `try...except ValueError` 忽略无法转换为数字的输入，避免错误输入导致回调中断。

## 组件选择

| 组件 | 交互方式 | 适用场景 |
| --- | --- | --- |
| `Slider` | 拖动连续数值 | 频率、振幅、阈值、透明度 |
| `Button` | 点击执行操作 | 刷新数据、重置状态、触发计算 |
| `CheckButtons` | 同时选择多个选项 | 显示或隐藏多条曲线、图层 |
| `RadioButtons` | 选择一个互斥选项 | 切换函数、图表类型、数据源 |
| `TextBox` | 输入文本或数值 | 精确参数、自定义文本、查询条件 |

## 通用开发模式

Matplotlib 交互组件通常遵循下面的结构：

```python
# 1. 创建 Figure 和 Axes
fig, ax = plt.subplots()

# 2. 创建需要动态更新的 Artist
(line,) = ax.plot(x, y)

# 3. 为控件预留 Axes
control_ax = fig.add_axes((left, bottom, width, height))

# 4. 创建交互组件
control = Slider(control_ax, "参数", 0, 10, valinit=1)

# 5. 编写更新逻辑

def update(value):
    line.set_ydata(calculate(value))
    fig.canvas.draw_idle()

# 6. 注册回调
control.on_changed(update)
```

常见的更新操作包括：

- 曲线数据：`line.set_data()`、`line.set_ydata()`
- 曲线可见性：`line.set_visible()`
- 坐标范围：`ax.set_xlim()`、`ax.set_ylim()`
- 数据范围：`ax.relim()`、`ax.autoscale_view()`
- 画布重绘：`fig.canvas.draw_idle()`

## 注意事项

### 预留控件空间

控件也是 Figure 中的 Axes。如果不调整布局，控件可能覆盖图表内容。可以使用 `fig.subplots_adjust()` 为控件预留底部或左侧空间：

```python
fig.subplots_adjust(bottom=0.25)
```

### 保持对象引用

需要将控件保存到变量中，避免对象被垃圾回收：

```python
slider = Slider(slider_ax, "频率", 0.1, 5.0)
button = Button(button_ax, "刷新")
```

### 使用回调更新 Artist

交互回调中优先修改已有 Artist，而不是每次操作都创建新的曲线。这样可以减少对象数量并提升交互性能：

```python
def update(value):
    line.set_ydata(np.sin(value * x))
    fig.canvas.draw_idle()
```

### 选择合适的后端
交互组件需要支持交互的 Matplotlib 后端。在 Jupyter Notebook 中可以使用：
```python
%matplotlib widget
```
如果只使用静态后端，滑块和按钮通常无法正常响应用户操作。
## 总结

- Matplotlib 交互组件位于 `matplotlib.widgets` 模块。

- 所有的组件步骤都是：
    创建对应的组件子区域 subplot
    创建组件实例 添加到
    注册交互回调函数
