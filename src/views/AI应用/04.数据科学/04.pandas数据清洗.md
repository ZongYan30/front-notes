# Pandas 数据清洗

数据清洗是数据分析中最耗时、也最重要的环节。真实数据常常存在类型不统一、格式不一致、缺失值和异常值等问题。

本节以一份程序员薪资调查数据为例，完成一轮完整的数据清洗，核心目标是统一字段类型，让数据可用于后续统计分析。

## 应届信息提取

原始数据中有 `26应届`、`25应届` 等值混入「城市」和「经验」列。这些值实际表示毕业年份，应单独提取为「毕业年份」列。

`str.extract()` 可按正则表达式提取匹配内容：

```python
col_name = '城市'
temp_mask = df[col_name].astype(str).str.contains('应届', na=False)

# 提取“26应届”中的 26
# df.loc[temp_mask, col_name].astype(str).str.extract(r'(\d+)\s*应届')
```

对「城市」和「经验」两列统一处理：城市中的应届值置为空，经验中的应届值按 0 年处理。

```python
df['毕业年份'] = np.nan

for col in ['城市', '经验']:
    mask = df[col].astype(str).str.contains(r'应届', na=False)
    year = df.loc[mask, col].astype(str).str.extract(r'(\d+)\s*应届')

    if not year.empty:
        df.loc[mask, '毕业年份'] = 2000 + year[0].dropna().astype(int)

    if col == '经验':
        df.loc[mask, col] = 0.0
    else:
        df.loc[mask, col] = None
```

## 城市清洗

城市列存在前后空格、省市组合格式和明显异常值，例如「湖南/株洲」「北京 」「焦虑型人格」「-」。

处理策略：

1. 使用 `str.strip()` 删除前后空格。
2. 对「省/市」格式取最后一段城市名。
3. 将已知异常值设为缺失。
4. 处理个别不规范城市名称。

```python
# 删除前后空格
df['城市'] = df['城市'].str.strip()

# “湖南/株洲”转换为“株洲”
df['城市'] = df['城市'].str.split('/').str[-1].str.strip()

# 删除明显不是城市的值
not_cities = ['焦虑型人格', '在读', '-']
df.loc[df['城市'].isin(not_cities), '城市'] = None

# 修正规范外的城市名
df.loc[df['城市'] == '广西柳州', '城市'] = '柳州'

# 查看清洗结果
df['城市'].value_counts()
```

## 经验清洗

「经验」的目标类型为以年为单位的数值型数据。原始值包含年、月、下限、加号、复合经历和异常文本等不同格式。

| 原始格式 | 处理规则 |
| --- | --- |
| `3年`、`2.5年` | 提取数值 |
| `3个月`、`4个月` | 除以 12 转换为年 |
| `<1年`、`<3年` | 取上限减 0.5 的近似值 |
| `10+年`、`15年+` | 取下限值 |
| `6年前端\n2年转行` | 将所有年数相加 |
| `应届`、`毕业`、`大一`、`大三` | 视为 0 年 |
| `转行`、`读研`、`上海`、`-` | 设为缺失值 |

通过自定义函数配合 `apply()` 处理：

```python
def parse_experience(val):
    if pd.isna(val):
        return np.nan
    if isinstance(val, (int, float)):
        return float(val)

    s = str(val).strip()
    if s in ['-', '']:
        return np.nan
    if s in ['转行', '读研', '上海']:
        return np.nan
    if '应届' in s or '毕业' in s:
        return 0.0
    if s in ['大一', '大三']:
        return 0.0

    plus_match = re.search(r'(\d+(?:\.\d+)?)\s*\+\s*年', s)
    if plus_match:
        return float(plus_match.group(1))

    lt_match = re.search(r'<(\d+(?:\.\d+)?)\s*年', s)
    if lt_match:
        v = float(lt_match.group(1))
        return max(v - 0.5, 0)

    years = re.findall(r'(\d+(?:\.\d+)?)\s*年', s)
    if years:
        return sum(float(y) for y in years)

    months = re.findall(r'(\d+)\s*个月', s)
    if months:
        return round(sum(float(m) for m in months) / 12, 1)

    return np.nan


df['经验'] = df['经验'].apply(parse_experience)
```

## 薪资清洗

薪资列包含月薪、年薪、多行文本、薪资变化历史和异常值等格式，清洗后统一为 **千元/月**。

| 原始格式 | 处理规则 |
| --- | --- |
| `9k`、`10k` | 提取数值 |
| `20w/年` | 年薪转换为月薪：`20 × 10 ÷ 12` |
| `13k*15` | 提取基本月薪 |
| `30k+`、`25+k` | 提取数值 |
| `前端：20k\n转行：28k` | 取最后一行 |
| `25k->22k->18k` | 取最新值 |
| `16k（广州）` | 去掉括号中的说明 |
| `50k~60k`、`20k/30k` | 按匹配规则提取数值 |
| `实习`、`-`、`？？` | 设为缺失值 |

```python
def parse_salary(val):
    if pd.isna(val):
        return np.nan

    s = str(val).strip()
    if s in ['实习', '-', '？？', '']:
        return np.nan

    # 多行薪资取最后一行
    if '\n' in s:
        s = s.split('\n')[-1].strip()

    # 薪资变动历史取最新值
    if '->' in s:
        s = s.split('->')[-1].strip()

    # 删除括号说明
    s = re.sub(r'[（(][^)）]*[)）]', '', s).strip()

    # 年薪 w 转换为千元月薪
    w_match = re.search(r'(\d+(?:\.\d+)?)\s*w', s, re.IGNORECASE)
    if w_match:
        return round(float(w_match.group(1)) * 10 / 12, 1)

    # “20k/30k”取后一项
    slash_match = re.search(
        r'(\d+(?:\.\d+)?)\s*k\s*/\s*(\d+(?:\.\d+)?)\s*k',
        s,
        re.IGNORECASE,
    )
    if slash_match:
        return float(slash_match.group(2))

    # 普通 k 单位月薪
    k_match = re.search(r'(\d+(?:\.\d+)?)\s*\+?\s*k', s, re.IGNORECASE)
    if k_match:
        return float(k_match.group(1))

    return np.nan


df['薪资'] = df['薪资'].apply(parse_salary)
```
