# Seaborn 分析前端开发者薪资数据

Seaborn 是建立在 Matplotlib 之上的高级统计可视化库。相比直接使用 Matplotlib，Seaborn 通常只需要较少代码，就能生成美观且具有统计意义的图表。

本节通过分析一份前端开发者薪资调查数据，学习 Seaborn 中常见的统计图表：

- 分布图：观察单个数值变量的整体分布
- 箱线图和小提琴图：比较不同类别下的数据分布
- 柱状图：比较不同类别的均值及其置信区间
- 散点图和回归图：观察两个数值变量之间的关系

## 环境准备

安装 Seaborn 及其依赖：

```bash
uv add seaborn pandas matplotlib ipympl
```

在 Notebook 中启用交互式后端：

```python
%matplotlib widget
```

导入依赖并设置全局绘图样式：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

plt.rcParams.update({
    "font.sans-serif": ["PingFang SC"],
    "axes.unicode_minus": False,
    "figure.dpi": 100,
})


def reset():
    plt.close("all")


sns.set_theme(style="whitegrid", font="PingFang SC")
```

`set_theme()` 可以统一设置 Seaborn 的绘图主题。`whitegrid` 会在图表中添加浅色网格，便于读取数值。

## 数据准备

读取数据并查看前几行：

```python
df = pd.read_csv("../linking_clean.csv")
df.head()
```

薪资分析需要排除薪资为空的数据：

df_clean = df.dropna(subset=["薪资(k)"]).copy()

```python
print(df_clean.columns)
print(df_clean.info())
print(df_clean.isna().sum())
```

## 薪资分布：单变量分析

首先使用 `histplot()` 和 `kdeplot()` 查看薪资的整体分布：

- `histplot()`：绘制直方图，展示数据在不同区间内的频数
- `kdeplot()`：使用核密度估计平滑地展示概率密度

### 直方图与核密度图

```python
reset()
fig, axes = plt.subplots(1, 2, figsize=(8, 4))

sns.histplot(
    data=df_clean,
    x="薪资(k)",
    bins=30,
    ax=axes[0],
)
axes[0].set_title("薪资直方图")

sns.kdeplot(
    data=df_clean,
    x="薪资(k)",
    fill=True,
    ax=axes[1],
)
axes[1].set_title("薪资核密度估计")

plt.tight_layout()
```

`bins=30` 将薪资范围划分为 30 个区间。区间数量越多，图表越细致，但也可能放大随机波动；区间数量过少则可能隐藏分布特征。

### 使用 `displot()` 快速绘制分布图

`displot()` 是一个 figure-level 函数，可以快速创建完整的分布图，并通过 `kde=True` 同时显示核密度曲线：

```python
reset()

sns.displot(
    data=df_clean,
    x="薪资(k)",
    kde=True,
    bins=30,
)
```

与 `histplot()`、`kdeplot()` 相比，`displot()` 更适合快速探索数据。需要精细控制多个子图时，则可以使用前面的 Axes-level 函数。

### 给直方图添加数值标签

直方图中的每个柱体都是一个 Rectangle Artist，可以遍历 `ax.patches` 为柱体添加频数标签：

```python
fig, ax = plt.subplots(figsize=(8, 4))
sns.histplot(
    data=df_clean,
    x="薪资(k)",
    bins=30,
    ax=ax,
)

for patch in ax.patches:
    height = patch.get_height()
    if height > 0:
        ax.text(
            patch.get_x() + patch.get_width() / 2,
            height,
            f"{int(height)}",
            ha="center",
            va="bottom",
            fontsize=8,
        )

plt.tight_layout()
```

## 学历与薪资：分类对比

使用 `boxplot()` 和 `violinplot()` 比较不同学历的薪资分布：

- `boxplot()`：展示中位数、上下四分位数和异常值
- `violinplot()`：在箱线图信息的基础上展示数据的分布形状

### 检查学历类别

绘图前可以先统计每个学历类别的样本数量：

```python
df["学历"].value_counts()
```

为了让学历按照合理顺序显示，可以显式指定 `order`：

```python
education_order = [
    "小学",
    "中专",
    "初中",
    "高中",
    "大专",
    "本科",
    "硕士",
]
```

### 箱线图与小提琴图

```python
reset()
fig, axes = plt.subplots(1, 2, figsize=(8, 5))

sns.boxplot(
    data=df_clean,
    x="学历",
    y="薪资(k)",
    order=education_order,
    ax=axes[0],
)
axes[0].set_title("学历与薪资：箱线图")

sns.violinplot(
    data=df_clean,
    x="学历",
    y="薪资(k)",
    order=education_order,
    ax=axes[1],
)
axes[1].set_title("学历与薪资：小提琴图")

plt.tight_layout()
```

箱线图适合快速比较不同类别的中位数、离散程度和异常值。小提琴图可以进一步观察数据集中在哪些区间，以及分布是否存在多个峰值。

### 使用柱状图比较平均薪资

`barplot()` 默认会计算每个类别的均值，并显示估计的置信区间：

```python
reset()

sns.barplot(
    data=df_clean,
    x="学历",
    y="薪资(k)",
    order=education_order,
)
plt.title("学历与薪资平均值")
plt.tight_layout()
```

柱状图适合比较总体水平，但它只展示聚合结果。分析薪资差异时，建议同时查看箱线图或小提琴图，以免忽略类别内部的分布和异常值。

## 经验与薪资：回归分析

使用 `scatterplot()` 观察工作经验与薪资之间的关系，再使用 `regplot()` 添加线性回归线：

- `scatterplot()`：展示每条数据记录的分布
- `regplot()`：在散点图基础上拟合并绘制回归线

```python
reset()
fig, axes = plt.subplots(1, 2, figsize=(8, 5))

sns.scatterplot(
    data=df_clean,
    x="经验(年)",
    y="薪资(k)",
    alpha=0.6,
    ax=axes[0],
)
axes[0].set_title("经验与薪资：散点图")

sns.regplot(
    data=df_clean,
    x="经验(年)",
    y="薪资(k)",
    scatter_kws={"alpha": 0.5},
    line_kws={"color": "red", "linewidth": 2},
    ax=axes[1],
)
axes[1].set_title("经验与薪资：回归图")

plt.tight_layout()
```

通过散点图可以观察数据是否具有明显的线性趋势、离群点或分组现象。回归线则可以帮助判断经验增加时薪资的整体变化方向。

需要注意，回归线反映的是相关关系，不代表经验增加一定会直接导致薪资增加。实际薪资还可能受到城市、技术栈、公司规模、职位级别等因素影响。

## Seaborn 的两类绘图函数

Seaborn 的绘图函数大致可以分为两类：

### Axes-level 函数

这类函数绘制到指定的 Axes 上，例如：

```python
fig, ax = plt.subplots()
sns.histplot(data=df_clean, x="薪资(k)", ax=ax)
```

常见函数包括：

- `histplot()`
- `kdeplot()`
- `boxplot()`
- `violinplot()`
- `barplot()`
- `scatterplot()`
- `regplot()`

它们适合和 Matplotlib 的 `subplots()` 一起使用，可以精确控制多个子图的布局。

### Figure-level 函数

这类函数会自行创建完整的 Figure，例如：

```python
sns.displot(data=df_clean, x="薪资(k)", kde=True)
```

常见函数包括：

- `displot()`
- `catplot()`
- `relplot()`
- `lmplot()`

它们适合快速绘制分面图和探索性分析，但布局控制方式与 Axes-level 函数不同。

## 常用参数

| 参数      | 作用             |
| ------- | -------------- |
| `data`  | 要使用的 DataFrame |
| `x`     | x 轴对应的字段       |
| `y`     | y 轴对应的字段       |
| `hue`   | 按类别使用不同颜色      |
| `style` | 按类别使用不同点形或线形   |
| `size`  | 按数值或类别控制点大小    |
| `order` | 指定分类变量的显示顺序    |
| `bins`  | 直方图的区间数量       |
| `alpha` | 设置透明度          |
| `ax`    | 指定绘制目标 Axes    |
| `fill`  | 是否填充密度图区域      |

例如，可以使用 `hue` 对不同城市的薪资进行分组：

```python
sns.scatterplot(
    data=df_clean,
    x="经验(年)",
    y="薪资(k)",
    hue="城市",
    alpha=0.7,
)
```
