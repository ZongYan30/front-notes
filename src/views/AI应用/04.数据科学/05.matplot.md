# Matplotlib 核心概念

<img src="https://zongyan30.github.io/front-assets/agent/matplot.png" width="100%">

Matplotlib 是整个 Python 数据可视化生态的基石。无论使用 Seaborn、Plotly 还是其他高级库，底层都离不开 Matplotlib 的三层架构。

本节重点理解 `Figure`、`Axes` 和 `Artist` 三个核心对象及其关系。

## 环境准备

安装 Matplotlib 和 Jupyter 交互式绘图后端：

```bash
uv add matplotlib ipympl
```

在 Notebook 中启用交互式后端：

```python
%matplotlib widget
```

导入依赖并设置绘图参数：

```python
import numpy as np
import matplotlib.pyplot as plt

# 设置中文字体支持（可选）
plt.rcParams.update({
    "font.sans-serif": ["PingFang SC"],
    "axes.unicode_minus": False,
    "figure.dpi": 100,
})
```

## Figure：画布

`Figure` 是最顶层的容器，相当于一张画布。一个 `Figure` 可以包含一个或多个 `Axes`（绘图区）。

创建 Figure 最标准的方式是使用 `plt.subplots()`：

```python
fig, ax = plt.subplots(figsize=(8, 4))  # 一张画布 + 一个绘图区
ax.plot([1, 2, 3], [1, 4, 9], marker="o")
```

### 创建多个 Axes

通过 `plt.subplots()` 的行列参数，可以在一张画布中创建多个绘图区：

```python
fig, axes = plt.subplots(2, 2, figsize=(8, 6))

axes[0, 0].plot([1, 2, 3], [1, 4, 9])
axes[0, 1].bar([1, 2, 3], [3, 5, 2])
axes[1, 0].scatter([1, 2, 3], [1, 4, 9])
axes[1, 1].hist(np.random.randn(10000), bins=100)
```

### 切换主题样式

Figure 可以通过 `plt.style.use()` 切换整体视觉风格，影响所有 Axes 的配色、网格和字体等属性。

查看可用样式：

```python
print(plt.style.available)
```

使用 `ggplot` 样式：

```python
plt.style.use("ggplot")

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot([1, 2, 3], [1, 4, 9])
ax.bar([1, 2, 3], [3, 5, 2], alpha=0.5)
```

恢复默认样式：

```python
plt.style.use("default")
```

## Axes：绘图区

`Axes` 是 Figure 内部的独立绘图区域，数据实际被绘制在 Axes 上。每个 Axes 都有自己的坐标空间、坐标轴、刻度和标签。

一个常见误区是：`Axes` 不等于 `Axis`。一个 Axes 通常包含两个 Axis，分别对应 x 轴和 y 轴。

### 基本坐标设置

```python
fig, ax = plt.subplots(figsize=(8, 4))

x = np.linspace(0, 10, 100)
ax.plot(x, np.sin(x), label="sin")
ax.plot(x, np.cos(x), label="cos")

ax.set_title("三角函数")
ax.set_xlabel("X 轴")
ax.set_ylabel("Y 轴", rotation=0)
ax.set_xlim(0, 10)
ax.set_ylim(-1.5, 1.5)
ax.legend()
ax.grid(True, linestyle=":", alpha=0.5)
```

常见坐标设置方法：

| 方法 | 作用 |
| --- | --- |
| `set_title()` | 设置标题 |
| `set_xlabel()` | 设置 x 轴标签 |
| `set_ylabel()` | 设置 y 轴标签 |
| `set_xlim()` | 设置 x 轴范围 |
| `set_ylim()` | 设置 y 轴范围 |
| `legend()` | 显示图例 |
| `grid()` | 显示网格 |

### 绘制 3D 图

创建 3D Axes 时，需要在 `add_subplot()` 中指定 `projection="3d"`：

```python
fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection="3d")

# 生成螺旋线数据
t = np.linspace(0, 20, 1000)
x = np.sin(t)
y = np.cos(t)
z = t

# 绘制 3D 线图
ax.plot(x, y, z, linewidth=2, color="red")

ax.set_xlabel("X 轴")
ax.set_ylabel("Y 轴")
ax.set_zlabel("Z 轴")
ax.set_title("3D 螺旋线示例")
```

### Spines：脊线

Axes 的四条边框线称为 `spines`。常见的简洁绘图风格是隐藏上、右两条脊线：

```python
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot([1, 2, 3], [1, 4, 9], linewidth=2)

ax.spines["top"].set_visible(False)
ax.spines["right"].set_visible(False)
ax.spines["left"].set_color("gray")
ax.spines["bottom"].set_linewidth(1.5)
```

### 注解与文本

`annotate()` 用于为图中的特定位置添加带箭头的注解，`text()` 用于在指定坐标添加普通文本。

```python
fig, ax = plt.subplots(figsize=(8, 4))

x = [1, 2, 3, 4, 5]
y = [1, 4, 9, 16, 25]
ax.plot(x, y, marker="o")

ax.annotate(
    "最大值",
    xy=(5, 25),
    xytext=(4, 23),
    arrowprops={
        "arrowstyle": "->",
        "color": "red",
    },
    fontsize=12,
)
ax.text(
    1,
    20,
    "二次函数",
    fontsize=14,
    style="italic",
    bbox={
        "boxstyle": "round",
        "facecolor": "wheat",
        "alpha": 0.5,
    },
)
```

## Artist：绘制元素

`Artist` 是 Matplotlib 中一切可见的东西。`Figure`、`Axes`、`Axis`、曲线、柱体、文字和图例等，都是 Artist。

绘图时，本质上是在不断创建和配置 Artist 对象：

```python
fig, ax = plt.subplots(figsize=(8, 4))

ax.plot(
    [1, 2, 3],
    [1, 4, 9],
    color="royalblue",
    linewidth=3,
    label="折线",
)
ax.bar(
    [4, 5, 6],
    [3, 7, 5],
    color="tomato",
    edgecolor="black",
    alpha=0.7,
    label="柱状图",
)
ax.scatter(
    [7, 8, 9],
    [8, 2, 6],
    color="green",
    s=100,
    label="散点",
)

ax.legend()
```

常见 Artist 及其对应方法：

| Artist | 常用方法 | 说明 |
| --- | --- | --- |
| `Line2D` | `plot()` | 折线、曲线 |
| `Rectangle` | `bar()` | 柱状图中的柱体 |
| `PathCollection` | `scatter()` | 散点集合 |
| `Text` | `text()`、`set_title()` | 文本和标题 |
| `Legend` | `legend()` | 图例 |

## 三层架构总结

```text
Figure（画布）
  ├── Axes（绘图区 1）
  │     ├── Axis（X 轴）
  │     ├── Axis（Y 轴）
  │     ├── Line2D（折线）
  │     ├── Rectangle（柱体）
  │     ├── Text（文字）
  │     ├── Legend（图例）
  │     └── ...
  ├── Axes（绘图区 2）
  │     └── ...
  └── ...
```

核心职责：

- `Figure` 负责容器和全局配置，例如画布大小、整体样式和布局。
- `Axes` 负责数据和坐标，例如绘制内容、坐标范围、标签和图例。
- `Artist` 负责视觉表现，例如颜色、线型、透明度和大小。

掌握这套概念体系后，遇到新的图表需求，可以准确判断应该查找 Figure API、Axes API，还是具体 Artist 的 API。
