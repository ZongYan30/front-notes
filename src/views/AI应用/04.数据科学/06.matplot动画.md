# Matplotlib 动画

Matplotlib 动画可以把静态图表变成动态过程，用于展示变化趋势、实时数据流或算法演化。

本节重点掌握 Matplotlib 的两种动画工具：

- `FuncAnimation`：通过更新函数逐帧修改图表
- `ArtistAnimation`：预先生成每一帧中的 Artist

同时介绍动画的性能优化、Notebook 展示方式以及 GIF、MP4 等导出方法。

## 环境准备

安装 Matplotlib、Jupyter 交互式绘图后端和 GIF 导出依赖：

```bash
uv add matplotlib ipympl pillow
```

如果需要导出 MP4，还需要在系统中安装 FFmpeg。

在 Notebook 中启用交互式后端：

```python
%matplotlib widget
```

导入依赖并配置绘图参数：

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import ArtistAnimation, FuncAnimation
from IPython.display import HTML
from collections import deque

plt.rcParams.update({
    "font.sans-serif": ["PingFang SC"],
    "axes.unicode_minus": False,
    "figure.dpi": 100,
})
```

重复运行 Notebook 单元格时，旧动画可能仍在后台运行。可以定义一个重置函数，在创建新动画前停止旧动画并关闭画布：

```python
def reset():
    old_ani = globals().pop("ani", None)

    if old_ani is not None:
        try:
            old_ani.event_source.stop()
        except Exception:
            pass

    plt.close("all")
```

## FuncAnimation：函数驱动动画

`FuncAnimation` 是最常用的动画方式。它会按照指定的帧序列，重复调用更新函数并修改图表中的 Artist。

核心三要素：

- `fig`：动画所在的画布
- `update(frame)`：每一帧调用的更新函数
- `frames`：帧数或提供帧数据的可迭代对象

### 正弦波动画

下面的示例通过不断改变正弦函数的相位，让曲线产生水平移动的效果：

```python
reset()
fig, ax = plt.subplots(figsize=(8, 4))

x = np.linspace(0, 2 * np.pi, 100)
(line,) = ax.plot(x, np.sin(x))

ax.set_ylim(-1.5, 1.5)
ax.set_title("正弦波动画")

frame_count = 50


def update(frame):
    phase = 2 * np.pi * frame / frame_count
    line.set_ydata(np.sin(x + phase))
    return (line,)


ani = FuncAnimation(
    fig,
    update,
    frames=range(frame_count + 1),
    interval=16,
    repeat=True,
)
```

最后一帧的相位为 `2π`，在视觉上与相位为 `0` 的第一帧一致，因此循环播放时衔接更加自然。

### 核心参数

| 参数 | 作用 |
| --- | --- |
| `fig` | 动画所在的 Figure |
| `func` | 每帧调用的更新函数 |
| `frames` | 帧数或可迭代对象，如 `range(100)`、`np.linspace(...)` |
| `interval` | 每帧间隔，单位为毫秒，默认值为 200 |
| `repeat` | 播放结束后是否循环，默认值为 `True` |
| `blit` | 是否只重新绘制发生变化的 Artist |
| `init_func` | 初始化函数，通常与 `blit=True` 配合使用 |
| `cache_frame_data` | 是否缓存帧数据；无限数据流通常应设为 `False` |

## 使用生成器模拟实时数据流

`frames` 不仅可以是整数或列表，也可以是生成器。动画每次从生成器中取得一条数据，再交给更新函数处理，因此适合展示实时数据流。

```python
reset()
fig, ax = plt.subplots(figsize=(8, 4))

# 只保留最近 100 个数据点
x_data = deque(maxlen=100)
y_data = deque(maxlen=100)

(line,) = ax.plot([], [], lw=2)

ax.set_xlim(0, 100)
ax.set_ylim(-1.5, 1.5)


def data_stream():
    t = 0
    while True:
        yield t, np.sin(t * 0.1)
        t += 1


def update(frame):
    x, y = frame
    x_data.append(x)
    y_data.append(y)

    line.set_data(x_data, y_data)

    # 数据超出初始范围后，移动 x 轴窗口
    if x >= 100:
        ax.set_xlim(x - 100, x)

    return (line,)


ani = FuncAnimation(
    fig,
    update,
    frames=data_stream(),
    interval=30,
    cache_frame_data=False,
)
```

这里使用 `deque(maxlen=100)` 自动移除过期数据，使图表始终只显示最近 100 个数据点。

由于生成器不会结束，应设置 `cache_frame_data=False`，避免 Matplotlib 持续缓存帧数据导致内存不断增长。

## Blit 模式

`blit=True` 表示每一帧只重新绘制发生变化的 Artist，而不是重新绘制整个 Axes。对于 Artist 较少、背景基本不变的动画，可以显著降低绘制开销。

使用 Blit 时通常需要：

1. 通过 `init_func` 初始化所有动态 Artist。
2. `init_func` 返回需要更新的 Artist。
3. `update` 同样返回发生变化的 Artist。

```python
reset()
fig, ax = plt.subplots(figsize=(8, 4))

x = np.linspace(0, 2 * np.pi, 100)
(line,) = ax.plot([], [], lw=2)
(point,) = ax.plot([], [], "ro", ms=8)


def init():
    ax.set_xlim(0, 2 * np.pi + 5)
    ax.set_ylim(-1.5, 1.5)
    return line, point


def update(frame):
    y = np.sin(x + frame * 0.1)
    line.set_data(x, y)
    point.set_data([x[-1]], [y[-1]])
    return line, point


ani = FuncAnimation(
    fig,
    update,
    frames=100,
    init_func=init,
    blit=True,
    interval=50,
)
```

如果更新函数会修改坐标轴范围、刻度或标题等 Axes 属性，通常需要重绘整个 Axes，此时不适合使用 Blit。

## ArtistAnimation：预生成帧

`ArtistAnimation` 适合已经准备好每一帧 Artist 的场景。它接收一个二维列表：外层列表表示所有帧，内层列表包含当前帧需要显示的 Artist。

```python
reset()
fig, ax = plt.subplots(figsize=(8, 4))

x = np.linspace(0, 2 * np.pi, 100)
artist_frames = []

for phase in np.linspace(0, 2 * np.pi, 50):
    (line,) = ax.plot(
        x,
        np.sin(x + phase),
        color="royalblue",
    )
    artist_frames.append([line])

ani = ArtistAnimation(
    fig,
    artist_frames,
    interval=50,
    repeat=True,
)
```

`ArtistAnimation` 会提前创建并保存所有帧，因此控制直观，但帧数较多或每帧 Artist 较复杂时会占用更多内存。

### 两种动画方式对比

| 对比项 | `FuncAnimation` | `ArtistAnimation` |
| --- | --- | --- |
| 帧生成方式 | 播放时调用函数动态更新 | 播放前生成所有帧 |
| 内存占用 | 通常较低 | 通常较高 |
| 实时数据 | 适合 | 不适合 |
| 帧内容控制 | 通过更新函数控制 | 直接定义每帧 Artist |
| 常见用途 | 实时曲线、算法过程、连续变化 | 帧数有限且内容已知的动画 |

## 保存动画

Matplotlib 可以将动画保存为 GIF、MP4 或嵌入式 HTML。

### 保存为 GIF

GIF 使用 Pillow writer，无需额外的视频编码器：

```python
ani.save("sine_wave.gif", writer="pillow", fps=20)
```

`fps=20` 表示每秒播放 20 帧。

### 保存为 MP4

MP4 使用 FFmpeg writer，需要系统已经安装 FFmpeg：

```python
ani.save("sine_wave.mp4", writer="ffmpeg", fps=20)
```

### 在 Notebook 中嵌入 HTML 动画

`to_jshtml()` 会生成带播放控件的 JavaScript 动画，无需额外播放器：

```python
HTML(ani.to_jshtml())
```

也可以生成 HTML5 视频，但需要 FFmpeg：

```python
HTML(ani.to_html5_video())
```

## 注意事项

### 保持动画对象引用

必须将动画对象保存到变量中，例如 `ani`。如果对象提前被垃圾回收，动画可能无法播放：

```python
ani = FuncAnimation(fig, update, frames=100)
```

### 更新函数的返回值

使用 `blit=True` 时，初始化函数和更新函数必须返回所有发生变化的 Artist：

```python
def update(frame):
    line.set_ydata(frame)
    return (line,)
```

单个 Artist 后面的逗号不能省略，因为返回值需要是元组或其他可迭代对象。

### 选择合适的帧间隔

`interval` 的单位是毫秒，近似帧率可以通过下面的公式计算：

```text
fps ≈ 1000 / interval
```

例如，`interval=50` 约等于每秒 20 帧。实际播放帧率还会受到绘图复杂度和运行环境的影响。

## 总结

- `FuncAnimation` 通过更新函数动态生成帧，是最常用的动画方式。
- `frames` 可以是整数、可迭代对象或生成器。
- 实时数据流应关闭帧缓存，防止内存持续增长。
- `blit=True` 只重绘变化的 Artist，适合背景不变的动画。
- `ArtistAnimation` 会预生成所有帧，适合帧数有限且内容已知的场景。
- 动画可以导出为 GIF、MP4，也可以直接嵌入 Notebook。
