## 新增知识

如果想在fastapi启动前执行一些操作，可以使用生命周期:

```python
from contextlib import asynccontextmanager
from collections.abc import AsyncGenerator

# 生命周期 推荐写成异步生成器
@asynccontextmanager
async def lifespan(_app: FastAPI) -> AsyncGenerator[None, None]:
    print("fastapi启动前==>执行一些操作")
    yield

app = FastAPI(
    lifespan=lifespan,
    title=web_setting.app_name,
    description=generate_error_docs(),
    docs_url=None if common_setting.environment == "production" else "/docs",
    redoc_url=None if common_setting.environment == "production" else "/redoc",
    openapi_url=(
        None if common_setting.environment == "production" else "/openapi.json"
    ),
)
```
