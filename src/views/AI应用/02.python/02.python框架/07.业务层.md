## 操作

复制本节课目录中的`duyi-service`下的所有文件，覆盖你的工程`apps/web-service`

## 核心关注点
> 询问ai下面的解决方案
1. 代码组织
   - 类模式还是函数模式？ (推荐类模式，因为可以通过基类扩展一些功能)
   - 异常怎么处理？(统一做一个异常处理层，对业务异常，数据库异常，dto异常进行处理)
2. 功能逻辑是否正确
   - 功能全不全？  (增删改查类的直接平铺，核心类的一点点审查)
   - 重要的验证做没做？
3. 边界是否清晰
   - 入参和返回的是什么？(必须都是DTO)
   - 是否耦合了接口层的东西？(业务层只处理业务，api接口返回的都应在api层)
