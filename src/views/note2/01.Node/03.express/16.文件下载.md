# 文件下载
## 文件下载原理
文件下载的核心就是http协议。

下面是一个文件下载的请求头:
```sh
HTTP/1.1 200 OK
Content-Type: image/png
Content-Length: 24567
Content-Disposition: attachment; filename="avatar.png"
Cache-Control: no-cache
Accept-Ranges: bytes
```

- Content-Type 文件类型
- Content-Length 文件内容大小
- Content-Disposition 浏览器处理方式
- Accept-Ranges 支持断点续传

## 文件下载实现
```js
const express = require("express");
const path = require("path");

const router = express.Router();

router.get("/:filename", (req, res) => {
  const absPath = path.resolve(
    __dirname,
    "../../resources",
    req.params.filename
  );
  res.download(absPath, req.params.filename);//下载文件
});

module.exports = router;
```

## 迅雷文件下载
支持迅雷下载，需要遵循迅雷下载的协议格式。

格式如下:
```
把完整的下载地址得到
    AA地址ZZ
    base64编码
    thunder://base64编码
```

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <a resrole="thunder" href="/res/hill.zip">下载</a>

    <script>
      const a = document.querySelector("a[resrole=thunder]");

      let thunderLink = `AA${a.href}ZZ`;
      thunderLink = btoa(thunderLink);
      thunderLink = "thunder://" + thunderLink;
      
      a.href = thunderLink;
    </script>
  </body>
</html>
```
