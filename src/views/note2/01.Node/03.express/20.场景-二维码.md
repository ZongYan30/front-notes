# 二维码
生成二维码一般使用第三方库

## 服务端生成
[qrcode](https://github.com/soldair/node-qrcode)

**安装**
```sh
npm install qrcode -S
```

**使用**
```js
const QRCode = require("qrcode");

// 生成文件二维码
QRCode.toFile( "./qrcode.png",(err) => {
  if (err) {
    console.log(err);
  } else {
    console.log("二维码生成成功");
  }
});

// 生成Base64编码的二维码图片
QRCode.toDataURL("https://duyi.ke.qq.com/?tuin=a5d48d54", (err, url) => {
  if (err) {
    console.log(err);
  } else {
    console.log(url);
  }
});
```

## 客户端生成
`qrcode`客户端生成的话需要自行使用构建工具打包，这里以CDN的方式演示

```html
 <script src="https://cdn.bootcdn.net/ajax/libs/qrcodejs/1.0.0/qrcode.js"></script>
```

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <!-- 二维码容器 -->
    <div id="divcode"></div>
    
    <script src="https://cdn.bootcdn.net/ajax/libs/qrcodejs/1.0.0/qrcode.js"></script>
    <script>
      new QRCode(divcode, {
        text: "http://yuanjin.tech",
        width: 128,
        height: 128,
        colorDark: "blue",
        colorLight: "#fff",
        correctLevel: QRCode.CorrectLevel.H,
      });
    </script>
  </body>
</html>
```
