# 图片防盗链
针对自己服务器的资源图片，为了防止其他网站直接访问，需要设置防盗防盗链。

## 原理
http请求头中有两个字段：
```sh
host: 服务器域名
Referer: 请求来源域名
```

如果Referer字段为空，或者不是服务器域名，就认为是其他网站直接访问，返回403错误或其他资源。

## 防盗链中间件
```js
const url = require("url");
const path = require("path");

module.exports = (req, res, next) => {
  const host = req.headers.host; //获取本网站的主机名（包括端口号）
  let referer = req.headers.referer;

  // 只处理图片
  const extname = path.extname(req.path);
  if (![".jpg", ".jpeg", ".png", ".gif"].includes(extname)) {
    next();
    return;
  }

  if (referer) {
    referer = url.parse(referer).host;
  }

  if (referer && host !== referer) {
    req.url = "/img/logo.jpg"; // url rewrite 重写请求路径到对外展示的图片资源
  }
  next();
};
```

> 该中间件可以放到静态资源中间件之前，确保图片资源被正确处理。
