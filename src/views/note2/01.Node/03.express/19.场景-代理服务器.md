# 代理服务器
在实际开发中，node往往是充当代理服务器的角色。客户端请求的node服务器,node服务器去请求数据服务器，将数据返回给客户端。

![代理服务器](https://zongyan30.github.io/front-assets/Node/代理服务器.jpg)

## 代理服务器中间件
希望将`/data`开头的请求，都代理到`http://yuanjin.tech:5100/api/xxxxx`

```
/data/api/xxxxx   --->  http://yuanjin.tech:5100/api/xxxx
```

```js
const http = require("http");

module.exports = (req, res, next) => {
  const context = "/data";

  //不需要代理
  if (!req.path.startsWith(context)) {
    next();
    return;
  }

  // 需要代理
  const path = req.path.substr(context.length);

  const request = http.request(
    {
      host: "yuanjin.tech",
      port: 5100,
      path: path,
      method: req.method,
      headers: req.headers,
    },
    (response) => {
      // 代理响应对象 response
      res.status(response.statusCode);
      for (const key in response.headers) {
        res.setHeader(key, response.headers[key]);
      }
      response.pipe(res);
    }
  );

  req.pipe(request); //把请求体写入到代理请求对象的请求体中
};
```

## 第三方库http-proxy-middleware
往往需要使用第三方库[http-proxy-middleware](https://github.com/chimurai/http-proxy-middleware)来实现代理服务器中间件。

> vue-cli的代理服务器就是使用的这个

**安装**
``` sh
npm install http-proxy-middleware -S
```

**使用**
```js
const httpProxyMiddleware = require("http-proxy-middleware");

const context = "/data";

module.exports = createProxyMiddleware(context, {
  target: "http://yuanjin.tech:5100",
  pathRewrite: function (path, req) {
    console.log(path.substr(context.length));
    return path.substr(context.length);
  },
});
```
