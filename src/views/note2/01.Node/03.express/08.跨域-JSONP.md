# 跨域
跨域:是浏览器制定的同源策略，不符合就会产生跨域。
**同源策略**: 协议+域名+端口需一致。
```sh
# 这两个就违反了同源策略
http://www.yuan.com:8001
http://www.yuan.com:8080
```

> 实际上，当客户端请求数据后，服务器是产生响应了，只是浏览器判断跨域了，拒绝把数据给客户端了。

## JSONP
JSONP: 是最初解决跨域的一种方式，现在已经不用了。
* 浏览器端生成一个script元素，访问数据接口
* 服务器响应一段JS代码，调用某个函数，并把响应的数据传入


JSONP的缺点：
1. 只能是get请求
2. 会严重影响服务器的正常响应格式，给服务器造成处理麻烦

## 示例
浏览器请求一个资源：
```js
// 生成一个script元素，访问数据接口
function jsonp(url) {
  const script = document.createElement("script");
  script.src = url;
  document.body.appendChild(script);
  script.onload = function () {
    script.remove();
  };
}

function callback(data) {
  console.log(data);
}

jsonp("http://localhost:5008/api/student");
```

服务端返回:
```js
router.get("/", async (req, res) => {
  const params = req.body;
  const result = await stuServ.getStudents(params);

  //需要返回一个js脚本给客户端,而不是json数据
  //如果某天另一个请求需要返回json格式，那么服务端又需要再次处理
  const json = JSON.stringify(result);
  const script = `callback(${json})`;
  res.header("content-type", "application/javascript").send(script);
});
```
