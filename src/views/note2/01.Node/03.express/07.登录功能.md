# 登录功能
一个完整的登录流程就是，前端发送请求，服务端根据账号密码判断是否登录成功。
如果登录成功，服务端会：创建token --> 响应给前端

但是中间远远的不止这么简单，我们可以先最小程度的实现一个mvp，把流程跑起来。

按照下面的步骤一点点实现即可:
* 登录-生成设置cookie
* 校验cookie - 通过放行  不通过-返回401 (写一个中间件)
* 白名单-处理登陆页面不进行cookie校验
* cookie的token加密  校验对cookie解密

## 工具库
先介绍下我们登录常用的中间件

### 1. cookie-parser
cookie-parser是一个用于解析cookie的中间件,无需安装。
```js
const cookieParser = require("cookie-parser");
app.use(cookieParser());
```

使用完cookie-parser后，req和res上都会挂载对应的cookie方法和属性。

```js
router.get("/login", (req, res) => {
    console.log(req.cookies);//可以获取当前的cookie

    res.cookie("token", "123456", {//设置cookie
        path: "/",// 所有路径都可以访问
        domain: "localhost",
        maxAge: 24 * 60 * 60 * 1000,// 24小时过期
    });
})
```

### 2. 第三方库path-to-regexp
path-to-regexp是一个用于将路径转换为正则表达式的中间件。
```sh
npm i path-to-regexp -S
```
经常用于对某些路由匹配
```js
//  /^\/student(?:\/([^\/#\?]+?))[\/#\?]?$/i
const { pathToRegexp } = require("path-to-regexp");
const reg = pathToRegexp("/student/:id");//生成对应的正则表达式
```

## 实现步骤
### 1. 设置cookie
登录的时候，设置一个cookie，发送给客户端
```js
const express = require('express')
const { getErr, getResult } = require('../utils');
const adminService = require('../../services/adminService');
const router = express.Router();

router.post("/login", async (req, res) => {
    const { loginId, password } = req.body;
    const result = await adminService.login(loginId, password);
    console.log("登录==>", result);

    if (!result) {
        res.status(401).send(getErr("登录失败", 401));
        return
    }

    const token = "IAMtOken";//生成token
    console.log("token==>", token);

    res.cookie("token", token, {
        path: "/",// 所有路径都可以访问
        domain: "localhost",
        maxAge: 24 * 60 * 60 * 1000,// 24小时过期
    });

    res.header("authorization", token);//有的不是web端,给请求头添加token
    res.send(getResult(result, `登录成功${loginId}`));
})


module.exports = router;
```
当客户端登录成功后，浏览器就会存储我们设置的cookie了。

### 2. 校验cookie
我们需要针对接口进行是否登录的鉴权,所以就很适合写一个中间件来进行

`authToken.js`
```js [authToken.js]
/* 验证token中间件 */
const { getErr } = require('../utils');
const { pathToRegexp } = require("path-to-regexp");

// 没有令牌
const hasNoToken = (res) => {
    res.status(401).send(getErr("你没有权限", 401));
}

module.exports = function (req, res, next) {
    // 校验token
    console.log("获取cookies==>", req.cookies);
    const token = req.cookies.token || req.headers.authorization;

    if (!token) {
        hasNoToken(res);
        return;
    }

    const loginId = token;
    req.loginId = loginId;//可以记录下当前登录操作的账号
    next();
}
```

然后在注册这个中间件

`routes/init.js`

```js [init.js]
//省略以上...
app.use("/static", express.static(staticPath));
app.use(express.urlencoded({ extended: true }));
app.use(express.json());
app.use(cookieParser());
app.use(require("./middleware/authToken"));//每个路由访问到达之前就先走鉴权校验

// 路由
app.use("/api/v1/admin", require("./api/admin"));
app.use("/api/v1/student", require("./api/students"));
app.use(require("./middleware/error"));

//省略以下...
```

### 3. 白名单
以上的鉴权，没有忽略掉登录页面，当登录接口来的时候依旧会进行鉴权。
需要在校验前添加一个白名单,这就用到了第三方库path-to-regexp

` authToken.js`

```js
// 省略以上...

const needTokenApi = [
    { method: "POST", path: "/api/v1/student" },
    { method: "PUT", path: "/api/v1/student/:id" },
    { method: "GET", path: "/api/v1/student" },
];

module.exports = function (req, res, next) {
    // 校验白名单
    const apis = needTokenApi.filter(item => {
        const reg = pathToRegexp(item.path);//生成对应的正则表达式
        return item.method == req.method && reg.regexp.test(req.path);
    })

    // 不需要鉴权的(登录接口)直接放行
    if (!apis.length) {
        next();
        return;
    }

    // 校验token...
}
```

### 4. token加密
上面生成token的时候，只是生成了一个字符串，但是这个字符串是明文，不安全的。
我们往往会对token进行加密，加密后的token才能安全传输。

**安装crypto-js库**
```sh
npm i crypto-js -S #一个三方加密库
```

**创建一个加密工具文件**

`[utils/encrypt.js]`

```js 
// 使用对称加密算法：aes 128
// 128位的秘钥
const secret = Buffer.from("mm7h3ck87ugk9l4a");
const crypto = require("crypto");

// 准备一个iv，随机向量
const iv = Buffer.from("jxkvxz97409u3m8c");

exports.encrypt = function (str) {
    const cry = crypto.createCipheriv("aes-128-cbc", secret, iv);
    let result = cry.update(str, "utf-8", "hex");
    result += cry.final("hex");
    return result;
};

exports.decrypt = function (str) {
    const decry = crypto.createDecipheriv("aes-128-cbc", secret, iv);
    let result = decry.update(str, "hex", "utf-8");
    result += decry.final("utf-8");
    return result;
};
```
**进行token加密**

`[routes/api/admin.js]`

```js
const { encrypt } = require('../../utils/encry');

router.post("/login", async (req, res) => {
    //...

    const token = encrypt(loginId);//生成一个加密token
    console.log("token==>", token);

    res.cookie("token", token, {
        path: "/",// 所有路径都可以访问
        domain: "localhost",
        maxAge: 24 * 60 * 60 * 1000,// 24小时过期
    });

    res.header("authorization", token);//有的不是web端,给请求头添加token
    res.send(getResult(result, `登录成功${loginId}`));
})
```

中间件校验token的时候进行解密

`[middleware/authToken.js]`

```js 
const { decrypt } = require('../../utils/encry');

module.exports = function (req, res, next) {
    // 校验白名单...

    // 校验token...
    console.log("获取cookies==>", req.cookies);
    const token = req.cookies.token || req.headers.authorization;

    if (!token) {
        hasNoToken(res);
        return;
    }

    const loginId = decrypt(token);//对token进行解密
    req.loginId = loginId;
    next();
}
```

这样一个初步的登录就实现了
