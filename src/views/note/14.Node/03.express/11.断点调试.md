# 断点调试
## 1. 开启断点调试
```json
  "scripts": {
    "start": "nodemon -x npm run server",
    "server": "node --inspect index"
  },
```

这个时候启动浏览器,F12打开后，会看到一个node的标志，表明已经开启了。

## 2. 在vscode中调试
node --inspect 启动模块，node进程会监听9229端口

.vscode中新增以下代码：
```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "node",
            "request": "attach",//选择附加到已存在的node进程
            "name": "启动程序",
            "port": 9229
        }
    ]
}
```
